# 隐私设计

UsageLoom 以本地优先为设计原则。它检查用户计算机上已经存在的用量数据，并通过本地 MCP 协议向调用方返回聚合报告。

Windows 0.4.0 客户端在本机展示结果，保留的 JavaScript/MCP 原型通过本地协议返回结果。客户端可以启动官方后端进行可选的独立授权；凭据由官方后端管理，UsageLoom 不直接读取凭据文件。扫描会读取 JSONL 字节和记录，只提取允许的元数据与计数，不保存会话正文。客户端还可能通过官方后端获取会话标题并在内存展示；下方“明确请求标题”的约束适用于旧 MCP 原型，不适用于桌面标题展示。

## Codex Adapter 可能读取的数据

Adapter 可能读取：

- 配置的 Codex 主目录下 `sessions/` 中的 JSONL 文件；
- 启用归档扫描时，`archived_sessions/` 中的 JSONL 文件；
- 只有在用户明确请求任务标题或按标题筛选时，才读取 `session_index.jsonl`；
- 本机安装的 `codex app-server` 进程返回的实时额度和账号用量信息。
- `account/read` 在缺少官方稳定 ID 时可能返回的电子邮箱；原生客户端只在内存中用它计算账户指纹。

扫描器只解析元数据和 Token 计数记录，不会有意读取提示词正文、助手回复、推理文本、工具输出或 `auth.json`。

## UsageLoom 不会发送的数据

本仓库不包含托管式 UsageLoom 服务、分析端点、HTTP 监听器、CDN 依赖或运行时遥测。报告只通过本地 MCP 协议返回给发起调用的客户端。

实时 Codex 查询会发送给本机安装的 Codex CLI 进程。Codex CLI 自行负责其身份验证和网络行为；UsageLoom 不读取、保存或转发 CLI 的 OAuth 凭据。

原生客户端在 `%LOCALAPPDATA%\UsageLoom\user-data\account-fingerprint.key` 保存一个本机随机密钥。它用 HMAC-SHA256 将规范化后的邮箱或官方 ID 转换为不可逆的本地指纹，用于隔离额度状态和通知去重。明文邮箱和原始账号 ID 不写入设置、SQLite、运行日志或诊断摘要。删除该密钥会使以前的指纹失效，应用会在下次查询时建立新的本地身份。

## 账号额度与本地历史的边界

- 实时额度通常对应查询时 Codex CLI 中已登录的账号。
- 本地 JSONL 是计算机上的历史记录，可能由此前登录过的其他账号产生。
- UsageLoom 不会根据当前登录状态把全部历史记录强行归到某个账号名下。
- 本地账户指纹只证明两次官方账号响应来自同一标识，不会把既有 JSONL Token 历史追溯归属到该账号。
- 原生客户端可把前后扫描均处于同一本机账户指纹下的新 Token 增量标记为“账号观察归属”。SQLite 和增量索引只保存不可逆的本机指纹；首次扫描、旧记录、未登录区间和账号切换边界不归属。该统计仅涵盖本机已观察日志，不代表账号在其他设备上的总用量。
- 实时查询失败后的 JSONL 额度快照可能已经过期，也可能来自其他账号；响应必须明确标记这种回退来源。
- API 等价费用只是按公开 API 单价计算的估算值，不代表订阅账单或订阅额度消耗。

## 敏感输出

项目目录名、任务标题、时间戳、模型名称和用量总计仍可能属于敏感信息。对于注重隐私的报告路径，应尽可能省略这些字段。错误诊断会截断，并清理常见 Bearer Token、疑似 Key、Cookie、电子邮箱和 Windows 用户路径。

分享诊断报告之前，请再次删除用户名、项目路径、任务标题、账号标识符以及可能暴露工作内容的时间戳。

## 任务标题

任务标题可能直接透露代码库、客户或工作内容，因此 UsageLoom 默认不读取标题索引。只有以下情况才应启用标题读取：

1. 用户明确要求显示任务标题；或
2. 用户明确要求按任务标题筛选。

仅需要总量、模型、日期或匿名 Session 统计时，不应读取标题。

## 新增 Provider 的要求

每个新增的 Provider Adapter 都必须记录：

1. 它具体读取哪些本地文件、API、Cookie 或环境变量；
2. 凭据会被持久化、刷新，还是只在内存中短暂使用；
3. 哪些数据会返回给 MCP 客户端；
4. 用户如何禁用该 Provider；
5. 适用的服务条款、速率限制和许可证；
6. 实时数据、缓存数据和本地历史如何区分。

如果某个 Provider 只能通过读取浏览器 Cookie、修改账号状态或采用不透明的第三方代理才能接入，应在实现前重新评估风险，不能默认纳入 UsageLoom。
