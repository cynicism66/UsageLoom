# UsageLoom 0.8.10

## 更新内容

- 修复托盘小窗在额度、Token、请求数、估值及缓存状态刷新时的布局抖动，复用现有卡片并原位更新数值。
- 为数值和状态文字预留稳定空间，取消刷新后的自动调整窗口高度和贴底定位；重新打开时在显示前完成测量，修正窗口边框造成的内容宽度偏差。
- 去掉托盘小窗 ⓘ 说明卡片中的“在设置中查看详情”按钮，保留简短说明和底部设置齿轮；完整详情仍位于“设置 → 每周容量估算（实验）→ 估值依据与工作负载”。
- 主窗口额度卡的详情入口继续保留。

## 数据与升级说明

- 本版只调整界面展示和窗口行为，不修改计价、Token 归属或额度采样算法，不清除历史，也不要求重新采样。
- API 等价估算仍是按有效采样工作负载计算的参考值，不是订阅账单或固定套餐额度承诺。

## 验证与安装说明

- 200 项核心回归与 14 项原型／公开仓库检查通过。
- 中英文各连续切换 18 次状态，窗口移动或缩放事件均为 0 次；控件布局保持稳定，隐藏后重新打开的尺寸一致。
- 隔离环境中的 10 个界面场景，以及当前估值、历史参考、无样本和重新核验状态的说明、设置导航、滚动、折叠与设置草稿保留检查通过。
- 自包含发行目录、MSI 结构、便携包与更新替换／回滚经过检查；未执行本机真实安装升级或不同缩放比例显示器之间的实机验收，不代表干净系统安装验收。
