# UsageLoom 0.9.13

## 更新内容

- **Codex 新增“只统计本机用量（忽略账号）”**：位于“设置 → 数据来源 → Codex”，默认关闭。开启后：
  - 不启动官方后端，不登录，不查询账号、额度和套餐；
  - 不做每周容量估算，也不把新用量归属到账号；
  - 本机 Codex 日志的 Token 统计照常，所有日志一起计入，不按账号区分；
  - 额度卡片显示“本地模式”，托盘图标不再取 Codex 额度（自动来源会改用 Claude，没有 Claude 时显示灰环）；
  - 登录、使用已有登录、立即计算容量等需要账号的操作会提示先关闭该选项。
- 开关时写入采样边界，前后的额度快照不会配对估算；已有历史、账号归属和估算记录都保留，关闭后恢复查询。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增“该开关属于采样来源”的检查。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查（隔离数据目录）：数据来源区和全局保存两条路径开关此选项，每次都写入边界并持久化；开启时手动和自动刷新都不查询，残留的额度快照被替换为本地模式，不记录额度观测，不连接后端；容量计算、登录和使用已有登录被拒绝；Codex 卡片仍显示。

真实账号下的后端调用情况只经代码审查和界面自检的模拟数据验证，没有连接真实账号测试；扫描时不记录账号这一项也只经代码审查。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
