# UsageLoom 0.7.5

## 本次更新（相对于 0.7.4）

- 修复额度查询中的重置周期短暂变化、随后恢复原周期时，当前有效采样进度被清零的问题。
- 在同账号、同套餐、同价格目录的连续观察中，保留已确认区间；原周期恢复且已用比例未倒退时，接回已有有效样本。
- 恢复时从返回原周期的快照建立新起点，不跨中间周期不同的时段拼接 Token 或额度下降。此前未成段的下降不会强行计入。
- 例如：已有 3 个确认百分点，观察到 4% 后临时出现另一周期，再返回原周期 4%，后来到 6%，显示为 `5/6（已确认 3、待确认 2）`，而不是清零或强行算满 6。
- 账号、套餐、价格目录变化及停用采样边界仍会隔离样本；本次不将异常快照解释为真实用量。
- 新增脱敏查询诊断，记录 stdio/proxy 通道、身份来源类型、采用的额度响应分支、周额度数值和重置时间；不记录凭据、邮箱、账号 ID 或完整响应。

## 下载与升级

- `UsageLoom-0.7.5-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.7.5-win-x64.zip`：自包含免安装版。
- 随附应用内更新清单及 SHA-256 校验文件。
- 保留 `%LOCALAPPDATA%\UsageLoom\user-data`；不要删除用户数据目录。下一次正常批量计算会根据仍保留的快照重算，无需清空历史。

## 验证与已知限制

- 核心回归测试 140 项通过，覆盖周期往返、异常时段排除、账号/套餐隔离和额度回退。
- 此次修复本地样本恢复逻辑，并不证明先前异常额度响应的根因；新增诊断只对升级后的查询生效。
- 此版本不修复此前 Windows Installer `1926 / 5`、`Config.Msi` 权限错误。遇到该错误请先处理未完成安装及权限问题，不要反复重装或删除回滚目录。
- 自动检查不代表已完成干净 Windows 系统上的实际 MSI 升级验收。
