# UsageLoom 0.8.8

## 更新内容

### 自动区分历史普通与 Fast 用量

- 按任务、模型及生效时间读取本地日志中的服务档位，历史记录使用当时的模式，不用现在的开关状态倒推全部用量。
- 修复关闭 Fast、明确清空档位或上下文冲突后，后续缺失模式字段可能重新继承旧 Fast 的问题；证据不足的部分保留为未知。
- Fast 与 Ultra 思考强度分别记录、分别处理。Astra Fast 使用对应的 API 等价费率，Ultra 不额外乘一个价格系数，推理 Token 不重复累计。
- 普通、Fast 或思考强度切换本身不会清空或重新开始额度采样。

### 旧数据安全补齐与自动重估

- 升级后正常扫描可从仍可读取的原始日志补齐模式信息；首次补齐前自动备份数据库。
- 保留 Token 计数、事件身份、已确认归属、采样历史、重新采样起点和已有核验依据，不要求清除历史或重新确认归属。
- 补齐完成后自动重新核验当前估值。金额可能因模式信息补全而变化，Token 数量与额度百分点不会因这次模式升级而改变。
- 原始日志已缺失或记录不足时保留已有历史，并明确说明无法恢复的模式，不猜测为普通或 Fast。

### 看清估值依据

- 在 ⓘ 说明中增加“估值依据与工作负载”详情，展示有效样本中的模型、模式和思考强度构成。
- 分开说明定价覆盖率、模式证据覆盖率和条件估算，避免把“有单价”误解为“全部费用已核实”。
- 紧凑说明弹层保持无滚动条，完整规则和中断原因在独立详情中查看。
- 历史参考与正在重新核验的结果明确标识，不冒充当前已确认估值。

## 估算边界

- API 等价值不是订阅账单、固定套餐价值或剩余 Token 承诺；订阅侧 Fast 消耗倍率不重复乘入 API 金额。
- 当前自动识别依据是本地请求设置，尚未核实服务器实际执行档位；界面会明确标注这一点。
- 当前已验证的 Fast 特殊计价适用于 Astra；其他模型缺少已核实特殊费率时保留未定价 Token，不套用 Astra 的倍率。
- 混合模式的每周估算反映有效样本的使用构成，不反推出各模型的独立额度，也不放宽账号、周期或连续性保护。

## 验证与安装说明

- 200 项核心回归与 14 项原型／公开仓库检查通过，覆盖计价、模式开关时间线、旧索引迁移、归属保留与采样连续性。
- 实际数据只读副本复算确认旧事件、计数索引、归属与采样控制记录保持不变，接受的采样区间结构一致；未修改运行中的用户数据库。
- 安装包结构与隔离环境中的程序启动、页面导航、估值详情和更新回滚进行验证；未在本机执行真实安装升级，不代表干净系统安装验收。
- 本版不修改原始日志，也不会自动批量认领未归属 Token。
