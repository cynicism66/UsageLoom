# UsageLoom 0.8.5

## 更新内容

### 每周容量估算维护

设置 → 每周容量估算（实验）新增三个入口：

- **修复计算数据**：先备份数据库，校验日志索引并重新计算；当前周期有未归属记录时，打开日期选择与归属确认，不自动认领其他账号或证据不足的记录。
- **清除计算历史**：清除所有账号的估算历史、样本和估算缓存，保留原始日志、Token、归属确认与原始额度快照。保存新的计算起点，避免后续扫描重新生成已经清除的旧估算。
- **重新开始采样**：为当前账号建立独立采样起点，旧样本不参与新一轮计算，历史估算仍可作为参考。

三个操作都需要确认，并在数据库的 `backups` 目录生成经过完整性检查的备份。修复与重新采样要求启用估算并有有效的当前周额度。维护期间阻止并发扫描、查询和归属操作，退出时等待维护结束。

### 修复新会话首条 Token 的归属边界

- 使用每个日志文件的字节快照捕获时间，而非整轮扫描起点，避免扫描过程中写入的首条记录被误判为未归属。
- 仍要求连续账号、来源和时间证据，不自动认领旧导入记录或未来时间记录。

## 验证与限制

- 157 项核心测试通过，包含维护事务回滚、清除起点持久化、备份、重采样隔离及首次扫描归属回归。
- 自包含构建、隔离界面启动与导航、安装包结构、便携包清单和更新回滚检查通过；未执行真实安装升级，不代表干净系统安装验收。
- 修复不能凭空补齐丢失日志、缺失额度快照或账号证据；不能安全计算的部分仍会排除并显示状态。
- 归属确认按所选日期执行，其他日期的未归属记录不会被一并认领。
- 不修改原始日志，不删除 Token 记录。程序包不包含用户数据库或本地核验数据。
