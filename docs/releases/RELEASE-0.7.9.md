# UsageLoom 0.7.9

## 本次更新（相对于 0.7.8）

- 托盘小窗的估算文字旁、详细额度页的周容量估算区域增加可点击的 ⓘ 按钮。
- 移除上述区域的采样悬浮提示，不再需要寻找文字命中范围或等待悬停触发；其他用途的提示保持不变。
- 点击入口查看估算与采样说明，支持点击外部或按 Esc 关闭。
- 说明框挂载到稳定的窗口容器，不依赖刷新时被重建的卡片；数据刷新时更新说明文字。
- 页面切换、窗口隐藏或关闭周容量估算时收起说明，避免残留；入口提供中英文辅助功能名称。

## 验证与范围

- 构建成功，核心测试 142/142 通过，中英文资源键校验通过。
- 独立模拟数据的有数据/空数据界面启动及重复导航检查通过；不涉及正式用户数据。
- 本次不改变 Token 统计、账号归属、采样算法或确认门槛，也不包含新增的归属变更后重算同步修复。
- 不包含托盘小窗展开抖动或 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）修复。
- 安装包静态校验不等于干净 Windows 系统上的实际升级验收。

## 下载与升级

- `UsageLoom-0.7.9-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.7.9-win-x64.zip`：Windows x64 便携版。
- 随附 `update.json` 和 SHA-256 校验文件，支持应用内检查更新；升级保留用户数据。
