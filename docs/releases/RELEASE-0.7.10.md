# UsageLoom 0.7.10

## 本次更新（相对于 0.7.9）

- 缩小托盘小窗及详细额度页的采样说明 ⓘ 入口：按钮从 32×32 调整为 22×22 DIP，图标从 16 调整为 12 DIP。
- 移除常态方块底色和边框，减少视觉占用；实际像素尺寸随 Windows 显示缩放变化。
- 保留点击查看说明、外部点击或 Esc 关闭以及中英文辅助功能名称，不恢复悬浮触发。

## 范围与验证

- 本版仅调整按钮样式，不改变 Token 统计、归属、采样算法或历史数据。
- 不包含归属变更后重算同步、托盘小窗展开抖动或 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）的修复。
- 构建成功；打包检查包含发布文件布局、ZIP 文件清单及 MSI 静态检查。静态检查不代表干净 Windows 系统上的实际升级验收。

## 下载与升级

- `UsageLoom-0.7.10-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.7.10-win-x64.zip`：Windows x64 便携版。
- 随附应用内更新清单 `update.json` 和 SHA-256 校验文件；升级保留用户数据。
