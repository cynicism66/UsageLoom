# UsageLoom 0.9.10

## 更新内容

- **Claude 历史趋势图的悬停说明增加“API 等价估算”**：鼠标停在某一天或某一小时上时，在 Token 数和额度消耗之间多显示一行折合的美元金额，例如“API 等价估算：$123.45”。
  - 金额按公开 Claude API 价格折算，是参考值，不是账单。
  - 当天有未定价的模型时，金额后标明“部分模型未定价”，这部分 Token 不计入金额。
  - 全部未定价或当天没有记录时显示 `--`，不写成 $0。

计价口径见 [Claude 接入说明](../claude-desktop-quota.md)。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：已定价、部分未定价、全部未定价和没有记录四种情况的文字；Claude 趋势图数据点的悬停说明带有这一行。去掉这一行的构建运行时，这项检查失败。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
