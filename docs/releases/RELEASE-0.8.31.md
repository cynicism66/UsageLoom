# UsageLoom 0.8.31

## 更新内容

- 设置页的更新节奏、通知、容量估算、登录缓存及独立登录选项按 AI 分成 Codex 和 Claude 桌面版独立卡片。Claude 尚不支持的选项以说明呈现，不显示无效开关；个性化和软件更新仍是全局设置。
- Claude 概览的日期选择与 Codex 统一为今日、近 7 天、本周、本月及自定义；汇总卡片统一为本机历史分解和四栏用量指标。
- 根据可识别的本机 Claude Code 日志，以公开 Claude API 模型价格显示所选范围内的“部分估算 · API 等价值”和定价覆盖率。普通输入、输出、缓存读取、5 分钟及 1 小时缓存写入分别估价；未知模型不按零收费。

## 使用与边界

Claude 估值只覆盖启用日志读取后能识别的本机 Claude Code 记录，可能遗漏 Chat、Cowork、网页、其他设备和已删除的日志。金额不是 Pro 套餐账单；由于没有全账号 Token 账本，不能据此推算每周套餐总容量或余额。部分价格条件和历史价格变化不可核实，详情入口会说明假设并链接[Claude 官方 API 价格](https://platform.claude.com/docs/en/about-claude/pricing)。

## 验证范围

运行核心回归、桌面界面冒烟和安装包结构检查。没有在用户电脑执行覆盖安装，也未获得普通 Chat／Cowork 的完整 Token 记录。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
