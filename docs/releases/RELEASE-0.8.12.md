# UsageLoom 0.8.12

## 更新内容

- 修复调整屏幕分辨率或缩放后，小窗右侧超出屏幕、卡片偏移或异常缩小的问题。
- 小窗显示期间自动检测当前屏幕的 DPI 和可用工作区变化，重新适配尺寸并将窗口保持在屏幕内；隐藏时不主动打开，下次从托盘打开时校正。
- 兼容副屏负坐标、工作区缩小和显示器移除后的最近屏幕定位；窄屏下不再由最小窗口宽度强行撑出工作区。
- 普通额度与用量刷新不触发重新定位，保留置顶状态，不增加滚动条。

## 数据与升级

- 不修改 Token 计数、账号归属、计价规则或采样历史，无需清除数据或重新采样。
- 更新后无需重启电脑；本版不自动修改 Windows 分辨率和缩放设置。

## 验证说明

- 自动回归覆盖多种 DPI、低分辨率、负坐标副屏、工作区边界和重复适配的稳定性。
- 原生界面检查覆盖过时窗口尺寸恢复、卡片对齐，以及连续数据更新和重新打开时的布局稳定性。
- 未在本机主动切换系统分辨率、缩放或拔插真实显示器；这些实际硬件切换场景仍需人工验收。未执行真实安装升级。
