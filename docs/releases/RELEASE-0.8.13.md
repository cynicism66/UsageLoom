# UsageLoom 0.8.13

## 更新内容

- 新增 Claude 桌面版额度显示：在概览、当前额度和托盘小窗中，同时查看 Codex 与 Claude。
- Claude 的 5 小时及每周剩余额度、重置时间来自本机缓存，无需在 UsageLoom 中额外登录。请在“设置 → Claude 桌面版”启用并保存。
- 展示真实快照时间。只有百分比时不猜测倒计时；重置时间已到但缓存未更新时，不擅自显示已恢复满额。
- 增加缓存来源选择、并发写入重试、格式／损坏保护及过期提示。读取不会访问 Cookie、登录凭据或聊天正文，不向 Claude 发起网络请求。
- 小窗新增固定高度的 Claude 区域，状态变化不重新缩放；保留分辨率、DPI 和工作区变化后的尺寸与位置适配。

## 使用边界

- Claude 是本地快照，不是实时联网额度查询。刷新按钮只重读缓存；缓存更新由 Claude 桌面版控制。
- 默认关闭；支持已验证的 Chromium Blockfile v3 与百分比历史 v2。多个来源需要在设置中核验。缓存不能证明当前登录身份。
- Token、请求、Session、费用与容量估值仍仅统计 Codex。无需清除历史或重新采样，本版不修改已有计数、归属与采样数据。
- 详见 [Claude 接入说明](https://github.com/cynicism66/UsageLoom/blob/main/docs/CLAUDE.md)。

## 验证说明

- 已在 Windows Claude 桌面版 2.2553.1.0（Pro）只读验证百分比与两项重置时间，并观察到新 5 小时周期的缓存更新。
- 自动检查覆盖缓存解析、压缩边界、来源隔离、过期与降级，以及双服务商原生界面和托盘小窗布局稳定性。
- 未执行真实安装升级，也未主动修改系统 DPI、分辨率或拔插显示器；其他 Claude 版本及实际硬件切换仍需进一步验收。
