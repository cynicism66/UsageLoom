# UsageLoom 0.7.6

## 本次更新（相对于 0.7.5）

- 修复临时额度查询超时、网络等可恢复故障导致此前已确认样本从当前累计中清除的问题。
- 为新中断记录保存原因，区分查询失败与主动重置、关闭采样等隔离边界。查询恢复后，仅在身份、套餐、价格目录和周期匹配时恢复有效样本。
- 连续查询失败保留恢复所需身份上下文，但不显示过期额度为实时结果；不跨中断区间强行配对 Token 与额度变化。
- 兼容旧版本未保存原因的中断记录：仅在保留日志中找到时间精确匹配的已知超时消息时恢复分类；证据不足的中断仍保持隔离。
- 原始额度快照不被改写。恢复依据以派生元数据保留，避免日志轮转后再次丢失恢复结果。

## 验证

- 核心回归测试 141 项通过，覆盖连续超时、主动重置与其他硬边界、账号/套餐隔离及历史超时证据匹配。
- 使用实际历史快照与用量记录进行只读离线复算，验证中断前后的两段有效样本可以合并，且不计入中断或异常周期之间的未配对用量。
- 构建成功；实际恢复进度取决于各客户端仍保留的快照、用量与诊断证据，不保证每个客户端都有可恢复样本。

## 下载与升级

- `UsageLoom-0.7.6-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.7.6-win-x64.zip`：自包含免安装版。
- 随附应用内更新清单和 SHA-256 校验文件。
- 保留 `%LOCALAPPDATA%\UsageLoom\user-data`，不要清空历史。升级后下一次正常批量计算会应用修复，仍保持五分钟批量节奏。

## 已知限制

- 此次不降低估算门槛，也不证明此前异常额度响应的上游根因。
- 不包含 Windows Installer `1926 / 5`、`Config.Msi` 权限错误修复；遇到该错误先处理未完成安装与权限问题，不要反复重装或删除回滚目录。
- 自动检查不代表已完成干净 Windows 系统上的实际 MSI 升级验收。
