# UsageLoom 0.7.2

## 本次更新

- 重新整理安装程序的“选择启动入口”页面，缩减多余空白，统一正文中文字体与内容左边距。
- “上一步”“下一步”“取消”使用相同尺寸和间距。
- 页面内加入 UsageLoom 图标；MSI 标题栏仍由 Windows Installer 管理。
- 精简快捷方式、固定任务栏与卸载说明。固定到任务栏仍需用户手动完成。

## 安装与升级

- MSI 为 Windows x64 自包含安装版；ZIP 为免安装版。
- 此次不改变安装目录、快捷方式默认选项、升级协议或用量统计算法。
- 用户数据仍保存在 `%LOCALAPPDATA%\UsageLoom\user-data`，请勿删除此目录。

## 验证边界

- 提供 MSI 控件布局、字体、图标和必要资源的自动检查。
- 自动检查不等于不同 DPI 下的人工验收，也不代表已在干净系统执行完整升级。
