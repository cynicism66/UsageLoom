# UsageLoom 0.9.8

## 更新内容

- **Claude 的 Session 显示会话名**：概览中的“最近 Session”和“Session 明细”的 Claude 标签不再只显示一串匿名标识，改为显示 Claude Code 自己记录的会话名：
  - 用 `/rename` 改过名的，显示改后的名称；
  - 否则显示 Claude Code 自动生成的标题；
  - 两者都没有时，仍显示匿名标识的前 12 位。
- Session 明细中悬停某个会话，可以看到它的匿名标识和项目目录，便于区分同名会话。

会话名只从会话文件里 Claude Code 写入的名称记录读取，在内存保留、最多 80 字，不读取提示词或回复正文，也不写入数据库或日志。详见 [隐私说明](../PRIVACY.md) 和 [Claude 接入说明](../claude-desktop-quota.md)。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增会话名读取检查：`/rename` 名称优先于自动标题，清除改名后回到自动标题，追加读取与改写文件后名称随之更新，子代理日志不改变会话名，超长名称截断、控制字符替换。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查；界面检查确认“最近 Session”显示会话名。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
