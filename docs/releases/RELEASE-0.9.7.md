# UsageLoom 0.9.7

## 更新内容

- **Token 趋势图的额度悬停说明只保留一行**：悬停某一天时只显示“每周额度消耗：N 个百分点”，不再附带“部分缺失 · 账号或来源屏障／观测断档……”和“非官方本地额度快照；不是 Token 换算值”两行说明，也不再加星号。
- **Claude 统计页移除“估算依据与限制”折叠区**：概览中的“部分估算 · API 等价值”和定价覆盖率照常显示，计价口径见 [Claude 接入说明](../claude-desktop-quota.md)。
- **Claude 统计页展开的区块不再自动折叠**：
  - 使用 Claude Code 时，额度快照大约每 30 秒更新一次，统计页随之重建，原来展开的“已知重置周期”“最近快照”“Token 构成”会被收起。
  - 现在重建后保持各区块原来的展开状态。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：展开一个“已知重置周期”后重建统计页，它仍展开，另一个仍收起；悬停说明只有一行。用不保留状态的构建运行时，这项检查失败。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
