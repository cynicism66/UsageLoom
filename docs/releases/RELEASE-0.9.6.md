# UsageLoom 0.9.6

## 更新内容

- **统计页不再显示“部分日志暂不能读取或记录不完整”提示**：
  - 少数 Claude Code 记录无法识别（例如计数前后矛盾）时，统计页顶部原来会一直挂着这张提示卡片，而用户也无从处理。
  - 现在照常统计已识别的部分，不再提示。
  - 未启用、找不到日志、读取失败等需要处理的情况，仍显示提示和“设置”按钮。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：“部分不完整”状态不显示提示，“读取失败”仍显示提示和设置按钮。用旧条件构建时，这项检查失败。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
