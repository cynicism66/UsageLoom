# UsageLoom 0.8.16

## 更新内容

- 当前额度页面的 Codex 名称、账号说明和套餐标识移入额度卡片顶部，使用与 Claude 一致的标题层级，不再在卡片外单独占两行。
- 套餐标识缩小后放在 Codex 标题右侧；保留原有大号剩余百分比、估算金额及详情入口。
- Codex 的多个通用额度窗口放在同一张卡片内；启用 Claude 时优先并排显示，窗口较窄时自动上下排列。Spark 专属额度仍单独展示。
- 本次仅调整页面布局，不修改用量记录、额度计算、账号归属或采样历史。

## 升级

0.8.14 及更新版本可通过应用内更新升级并确认 UAC。手动安装时，将 `UsageLoom-0.8.16-win-x64.msi` 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出软件后双击安装入口。无需卸载或清理本地数据。

## 验证范围

包含核心回归、Claude 设置保存与重启回归、桌面页面启动和服务商卡片层级及布局检查。未修改用户现有安装或真实数据。
