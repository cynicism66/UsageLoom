# UsageLoom 0.7.8

## 本次更新（相对于 0.7.7）

### 采样进度与重算同步

- 启动后，额度查询与本地索引就绪即执行首次周容量重算，不再等待五分钟后才更新旧缓存中的采样起点。
- 后续仍按原有批量节奏计算，不改为持续高频重算。
- 增加旧缓存显示 7/6、重算后应为 8/6 的回归场景，并验证新起点保存和重启恢复后保持一致，不是直接给进度加 1。

### 断线分类与安全续接

- app-server 连接断开使用专门的异常类型，作为查询失败处理，不再误记为主动重置采样。
- 对旧版误记的断线边界，仅在日志中找到精确时间对应的已知断线消息时恢复分类；保留原始快照，并保存恢复依据，避免日志轮转后再次丢失。
- 对超过 5 分钟、不超过 60 分钟的查询中断，只有断线后到恢复之间没有用量，且其他连续性条件全部满足时，才允许续接未成段起点。
- 同账号、套餐、定价版本、原周期、恢复时额度一致、后续快照确认和用量归属检查仍然保留。长间隔内有用量、缺失时间或存在不确定历史时不强行续接。
- 真正的账号切换、主动重置与其他没有证据的硬边界继续隔离。

## 验证与升级

- 核心测试 142/142 通过；覆盖首次立即重算、缓存往返、断线证据匹配及空闲/活跃中断边界。
- 实际数据库副本复算得到已确认 6、待确认 2、有效区间 2 段，即 8/6；重复事件数为 0。该数值仅对应此次核验数据，不是所有客户端的固定结果。
- 不修改原始用量日志，不删除用户历史；升级后先完成正常额度查询和本地索引，由程序重算。
- 提供 Windows x64 MSI 安装版、ZIP 便携版、应用内更新清单及 SHA-256 校验文件。

## 已知限制

- 不包含托盘小窗展开抖动修复。
- 未修复部分机器的 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）；安装包静态校验不等于干净 Windows 系统上的实际升级验收。
- 历史恢复依赖现存快照、用量及可验证日志，不能保证所有中断均可续接。
