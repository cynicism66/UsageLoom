# UsageLoom 0.8.11

## 更新内容

- 修复最近 Session 和 Session 明细中的名称获取问题，优先读取本机保存的显式会话名称，不再依赖额度查询中的标题接口。
- 启动时、手动扫描时以及后台自动更新标题；重命名后即使用量不变，界面也会刷新，无需清除历史或重建索引。
- 无名称的后台辅助会话显示“后台辅助会话”与短 ID；其他无法取得名称的记录显示“未获取标题”与短 ID，不再全部混为“未命名会话”。
- 兼容旧标题索引、归档会话和不同版本的状态数据库；临时读取失败保留同源内存名称，切换日志目录时隔离缓存。

## 数据与隐私

- 本版不修改 Token 计数、账号归属、计价或额度采样算法，不清除历史，不要求重新采样。
- 只读名称及会话类别元数据，不使用可能包含提示词的正文型字段生成标题；名称仅在本机内存展示，不写入用量数据库或运行日志，不上传。
- 真正没有名称的辅助会话不会被虚构一个任务标题。

## 验证与安装说明

- 核心回归覆盖标题索引、最新名称、后台辅助会话、旧数据库、归档、改名、读取失败、目录切换、只读及活动 WAL 数据。
- 原生界面检查覆盖概览与 Session 明细仅标题变化的刷新，以及既有页面导航与小窗稳定性。
- 安装包结构、便携包、更新替换与回滚经过检查；未执行本机真实安装升级，不代表干净系统安装验收。
