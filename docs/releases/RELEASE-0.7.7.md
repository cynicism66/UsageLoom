# UsageLoom 0.7.7

本次更新重点修复周容量估算中未完成采样区间在短暂中断后丢失的问题。

## 修复内容

- 0.7.6 只恢复已确认的完整样本；本版同时保存中断前尚未成段的采样起点，在证据充分时继续按原起点配对。
- 对临时查询失败，要求恢复间隔不超过 5 分钟；对周期短暂切换后回到原周期，要求间隔不超过 60 分钟，并且异常期间没有新增用量。
- 恢复必须满足同账号、套餐、价格目录和原重置周期，恢复时已用百分比与中断前一致，并由后续快照及索引确认。
- 检查整个待续接区间的用量归属；用户明确确认归属的记录可以参与重算，未归属或仅由重启推定的记录不能作为续接依据。
- 存在不确定用量、缺失时间、主动重置或身份隔离等情况时保持断开，不为凑足进度强行增加百分点。

## 数据与验证

- 不删除或改写原始额度快照、用量日志；按时间区间重算，避免同一用量重复累计。
- 数据库副本核验中，5 条已确认归属记录共 891,110 Token 全部进入有效区间，重复事件数为 0；这不是所有用户都会出现的固定恢复数值。
- 核心测试 141/141 通过；包含安全续接、异常期间存在用量、未归属、重启推定及硬边界隔离检查。
- 保留批量计算及有效区间确认门槛；更新后需完成额度查询和本地索引，再等待批量重算，不能保证所有历史缺口均可恢复。

## 下载与已知限制

- Windows x64 安装版：`UsageLoom-0.7.7-win-x64.msi`。
- Windows x64 便携版：`UsageLoom-0.7.7-win-x64.zip`。
- 随附 `update.json`，供应用检查和下载更新；升级保留用户数据。
- 本版不包含托盘小窗展开抖动修复，也未修复部分机器的 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）。
