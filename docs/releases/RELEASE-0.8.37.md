# UsageLoom 0.8.37

## 更新内容

- 减少 Claude 正在更新本地缓存时，托盘额度卡片反复显示“缓存读取失败或正在变化”的情况。读取会短暂重试；如果缓存仍不可读，但 Claude 的本机百分比历史已通过校验，则显示该历史快照。
- 历史快照会明确标为“仅百分比快照 · 无重置时间”，不会补造重置倒计时，也不会把它当作当前登录身份或实时额度。缓存和历史都不可读时，仍保留失败提示。

## 验证范围

已运行核心回归、桌面构建与界面冒烟、发行包结构检查。读取器已在本机只读复测，但这不能保证 Claude 每次写缓存时都不会出现短暂失败。没有修改 Claude 原始文件，也没有在用户电脑安装或关闭正在运行的应用。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
