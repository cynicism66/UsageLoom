# UsageLoom 0.8.3

## 更新内容

### 断网与重启恢复

- 重启检查点不再读取即删除，也不会因首次查询失败直接丢失；完整扫描和处理成功后才消费。
- 固定首次恢复终点，避免再次启动扩大历史推定范围。账号、来源路径或时间条件不符时不推定归属。
- 重启核验允许普通查询失败及迟到确认；保留短重启、同账号、同周期、事件匹配与索引覆盖检查。
- 暂时未登录、查询失败与明确换号分开处理；真实账号变化、主动登出和数据来源切换仍保持隔离。
- 短断网期间额度增长，在限定时间内有已归属用量且后续证据充分时可续接；长时间离线和无法解释的缺口不强行合并。

### 异常快照与重复计算

- 缺失或非法周额度快照、未确认的百分比回退先隔离，等待后续核验，界面不再仅凭一次回退立即清空显示。
- 同周期恢复正常后保留可恢复的已确认样本，异常区间不直接计入；持续回退和真实周期变化保持独立判断。
- 同一时刻的冲突快照及同一事件 ID 的冲突内容不作为可靠样本；正常重复输入去重，乱序输入按时间处理。
- 已明确属于其他账号或 Spark 的无时间记录不再阻断当前账号的断点续接；相关或未知归属的记录仍需可靠时间证据。

### 保存可靠性与等待说明

- 采样区间、历史结果和当前缓存统一事务保存，避免部分提交；写入失败不宣告计算完成。
- 同值额度刷新和无变化扫描不再无谓作废正在进行的计算；真实输入变化仍拒绝旧结果，并安排较快重试。
- 系统时钟回拨不会无限推迟批量重试。
- 说明框增加中断原因分组，明确“两分钟”是最短确认间隔，不是必定完成的时限。

## 验证与数据安全

- 151 项核心测试通过，包括重复/冲突输入、迟到确认、重启检查点、身份隔离及事务失败回滚。
- 应用构建、隔离数据启动与重复导航检查通过；数据库副本复算检查未发现重复计入。
- 不修改原始日志，不删除 Token 记录；未将用户数据库或核验工具包含在发布包中。
- 升级后完成额度查询和日志索引，会依照现存证据重新核验。证据不足的历史区间仍可能保持排除。

## 下载与限制

- `UsageLoom-0.8.3-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.8.3-win-x64.zip`：Windows x64 便携版。
- 提供应用内更新清单与 SHA-256 校验文件。
- 多设备用量无法仅凭本机日志完整核对；估算不等于官方账单。磁盘无法写入时，无法保证未落盘额度快照恢复。
- 未进行真实断电、物理磁盘写满或干净系统安装升级验收。本版不包含托盘展开抖动及 Windows Installer `Config.Msi` 权限错误的修复。
