# UsageLoom 0.8.18

## 更新内容

- 概览额度卡片顶部只显示“Codex”和套餐标识，去掉“在线额度摘要”。
- 托盘小窗的套餐标识移到顶部 Codex 额度卡片内，底部不再单独显示套餐。
- 套餐标题行保持固定高度，额度数值和缓存状态更新不改变小窗布局；保留现有统计、估算和刷新功能。
- 不改变已保存设置、用量记录、账号归属或采样历史。

## 升级

可在软件内检查更新并确认 UAC。手动安装时，将同版本 MSI 与 `UsageLoom-install.cmd` 放在同一目录，从托盘退出软件后双击安装入口，无需卸载或清理数据。

## 验证范围

包含核心测试、桌面页面和套餐标题布局检查、小窗连续刷新与显示尺寸恢复检查、Claude 设置保存与重启回归，以及打包和隔离安装升级检查。未替用户安装或修改真实数据。
