# UsageLoom 0.8.35

## 更新内容

- 概览中的 Codex 和 Claude 额度卡片采用更接近的排版：相同的标题字重、内容间距和进度条高度。各自的额度窗口与数据来源仍如实显示，不会用本机 Token 冒充 Claude 套餐总额度。
- Claude 的每周参考估算在概览卡片中改为一条简洁摘要；悬停信息图标可查看采样状态，完整证据仍留在额度详情页。
- 移除 Codex 卡片底部的“查看额度详情”按钮。

## 验证范围

运行核心回归、中文和英文桌面界面冒烟、安装包结构及发行附件校验。没有在用户电脑执行覆盖安装。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
