# UsageLoom 0.9.9

## 更新内容

- **历史趋势图横轴最右侧的日期不再重叠**：横轴按固定间隔标注日期，同时总会标注最后一天。选的日期范围恰好让最后一天紧挨着前一个标注时（例如 09-10 至 10-29），两组日期和数值会叠在一起看不清。现在最后一天的标注保留，离它太近的那个标注让位。Codex 与 Claude 的趋势图都已修正。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：在 4 种图表宽度下逐一检查 1–120 个数据点，横轴标注互不重叠且总有最后一天。改回原来的标注方式时，这项检查失败。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
