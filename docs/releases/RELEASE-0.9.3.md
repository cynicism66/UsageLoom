# UsageLoom 0.9.3

## 更新内容

- **托盘图标保留 Claude 的最后数值**：
  - 以前 Claude 额度快照超过 15 分钟没有更新（例如一段时间没打开 Claude Code），托盘图标就变成没有数字的灰环。
  - 现在继续显示最后一次的剩余百分比，圆环和数字改用暗色，表示不是最新数据；悬停说明附“最后更新”时间。
  - 已经过了重置时间的 5 小时或每周窗口按剩余 100% 计，因此闲置一夜后通常显示的是每周剩余。
  - 在网页、手机或其他电脑上使用 Claude 的消耗本机看不到，暗色数字可能偏高；重新使用 Claude Code 后会恢复正常颜色。
  - 概览、当前额度和托盘小窗的显示不变，仍会标明快照较旧。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增测试覆盖：
  - 超过 15 分钟的快照保留数值并标记为旧数据，15 分钟以内不标记；
  - 已过重置时间的窗口按满额计，两个窗口都已重置时显示 100；
  - 没有时间、时间在未来、来源停用或身份不确定时仍显示灰环；
  - 暗色图标的每个像素都不比正常图标亮，轮廓不变。
- Release 桌面构建、中文和英文的全页面界面冒烟。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。托盘图标的实际观感未在多种 DPI 下实机核对。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
