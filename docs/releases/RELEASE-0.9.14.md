# UsageLoom 0.9.14

## 更新内容

- **重置时间改为显示具体时刻**：额度下方不再显示“0 天 3 小时 50 分后重置”这样的倒计时，改为显示几点几分重置：
  - 今天或明天重置时显示“今天 14:30 重置”“明天 05:00 重置”；
  - 更远时显示日期和时刻，例如“11-16 05:00 重置”；
  - 鼠标停在这一行上可以看到倒计时；
  - 托盘小窗的 Codex 和 Claude、概览中的 Codex 和 Claude、Codex 额度页的 Spark 行都已改用这种显示。额度页原本已同时列出预计重置时间和倒计时的大卡片保持不变。
- **托盘小窗中 Claude 重置时间的悬停说明随刷新更新**：小窗会在剩余最少的窗口后面加上“节奏正常”等提示，并附悬停说明。以前这段悬停说明在后续刷新中不会更新，5 小时窗口重置后，鼠标停上去仍显示重置前的倒计时，与这一行实际显示的内容不一致。现在每次刷新都会同步更新。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增重置时刻检查：今天、明天、更远日期，午夜前后，时区换算，缺少重置时间与已过重置时间沿用原提示。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：托盘小窗连续 18 次刷新，覆盖有节奏提示、无节奏提示、窗口已重置和读取失败等情况，每次刷新后 Claude 两行都显示重置时刻，悬停说明与当前内容一致并附倒计时。去掉悬停修复、改回倒计时的两种构建分别运行时，这项检查失败。

时刻按本机时区显示。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
