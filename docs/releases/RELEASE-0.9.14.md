# UsageLoom 0.9.14

## 更新内容

- **托盘小窗中 Claude 重置时间的悬停说明随刷新更新**：小窗会在剩余最少的窗口后面加上“节奏正常”等提示，并附悬停说明。以前这段悬停说明在后续刷新中不会更新，5 小时窗口重置后，鼠标停上去仍显示重置前的倒计时（例如“0 天 0 小时 20 分后重置”），与这一行实际显示的时间不一致。现在每次刷新都会同步更新。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：托盘小窗连续 18 次刷新，覆盖有节奏提示、无节奏提示、窗口已重置和读取失败等情况，每次刷新后 Claude 两行的悬停说明都与当前文字一致。去掉修复的构建运行时，这项检查失败。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
