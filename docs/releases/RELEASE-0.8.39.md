# UsageLoom 0.8.39

## 更新内容

- Codex 和 Claude 的 5 小时、每周额度显示用量节奏。只有本地快照新鲜、来源明确且重置时间有效时才给出状态；这是已用额度与已过时间的比较，不是预测或官方结论。
- Token 趋势图的悬停提示增加额度消耗百分点，并注明使用 5 小时还是每周窗口。跨重置、断档或来源切换时，缺失部分会明确标记；没有观测不会显示为零。
- 打开用量小窗时，可对超过 60 秒的快照按需后台刷新。刷新期间保留已有值，卡片显示快照的新旧程度；设置里可以关闭打开即刷新。
- 托盘图标可显示所选来源最紧张窗口的剩余百分比圆环。低剩余量变为橙色或红色，不可信或过期时转灰并移除数字；设置里可选择来源或恢复固定 Logo。

所有额度与趋势标记均来自本地只读快照，不代表 Provider 官方计费或账单。额度消耗不换算 Token，不跨账号或来源合并。旧版 Codex 5 小时历史若未曾记录，不会补造。

## 验证范围与已知限制

已运行核心回归、Release 桌面构建和界面冒烟。托盘图标的像素及阈值逻辑已自动测试；当前隔离测试会话没有可见的 Explorer 通知区域，实际图标观感、DPI 切换、Explorer 重启及真实托盘交互仍需在桌面环境人工检查。本版不包含实验性的任务栏数字条。

本版将 .NET 运行时许可与第三方声明固定在源码的许可目录，避免构建机的 NuGet 缓存不含文本时发布失败。此前推送的 `v0.8.38` 仅是未发布候选标签，没有对应的 GitHub Release；不应作为安装版本。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
