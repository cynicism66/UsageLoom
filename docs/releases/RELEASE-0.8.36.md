# UsageLoom 0.8.36

## 更新内容

- Claude 每周额度参考估算无法生成数字时，概览卡片直接显示简短的实际原因，不再只写“暂不可估算”。
- 右侧信息图标现在可以点击，弹出完整原因、有效配对进度和适用边界；鼠标悬停也会提示其用途。
- 额度百分比包含本机 Claude Code 日志无法覆盖的用量时，仍不会强行换算成 Token。普通 Chat、Cowork、云端及其他设备都可能造成这种差异，程序不能仅凭本机数据判定具体来源。

## 验证范围

运行核心回归、中文和英文桌面界面冒烟、安装包结构及发行附件校验。没有在用户电脑执行覆盖安装。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
