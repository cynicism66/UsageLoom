# UsageLoom 0.8.6

## 更新内容

### 确认归属后立即重新核验

- 手动确认 Token 归属后立即请求重算，不再等待五分钟批量周期。
- 核验期间不继续展示旧的“账号归属待核验”结论，旧估算明确标为参考。
- 数据库已保存、后续读取或计算失败时，明确提示“归属已保存，估算尚未更新”，避免重复确认。
- 数据变化、额度过期、异常快照或计算失败时保持待核验，后续刷新按条件重试；只有有效计算结果应用后才结束待重算状态。
- 确认期间隔离并发计算、设置变更和身份续验，防止使用旧记录计算；账号来源变化后不沿用旧账号的待核验提示。

### 避免额度请求失败导致身份过期空档

- 自动刷新开启时，账号身份确认满三分钟后独立续验，不再受额度查询失败后的重试退避影响。
- 续验仅执行只读账号检查，不查询额度、不刷新登录凭据、不发起登录，也不将旧额度伪装为新快照。
- 保留五分钟身份有效期；身份无法确认、明确换号或认证失败时仍安全停止自动归属。
- 账号变更通知与进行中的请求互相校验，避免旧请求恢复已失效身份。

## 验证与限制

- 164 项核心测试通过，覆盖独立身份续验、网络/认证错误、账号变化、确认后即时重算、失败重试和真实连续性中断。
- 自包含程序、隔离界面启动与导航、MSI 结构、便携包清单和更新回滚检查通过；未执行真实安装升级，不代表干净系统安装验收。
- 已有未归属记录不会自动批量认领；用户已确认的归属继续保留。
- 确认账号归属不等于证明额度连续性。缺失快照、较长失败间隔内有用量、跨账号或跨重置等情况仍需独立核验，不强行合并。
- 不修改原始日志、不删除 Token，也不清除已有采样历史。关闭自动刷新时不会自动执行身份续验。
