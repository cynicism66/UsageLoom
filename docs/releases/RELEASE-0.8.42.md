# UsageLoom 0.8.42

## 更新内容

- 新增 Claude Code 状态栏额度快照。只用 Claude Code、不常开 Claude 桌面版时，也能在 UsageLoom 中看到最新的 5 小时和每周额度：
  - 安装包附带 `usageloom-statusline.js`。在“设置 → 数据来源 → Claude”中点击“复制设置”，粘贴到 Claude Code 的 `settings.json` 即可接入。
  - 脚本本身不显示任何内容。已有自己的状态栏时，在脚本路径后加 `--pass |` 再接原来的命令，原状态栏照常显示。
  - 脚本只保存两个额度的已用百分比和重置时间，不联网、不读凭据，也不记录会话、项目或费用。需要本机安装 Node.js。
- 状态栏快照和 Claude 桌面版缓存同时存在时，自动采用时间较新的一份，卡片说明会标明来源；两边的额度历史分开保存，不混合。
- 设置页显示最近一次状态栏快照的时间，以及当前显示的是哪一份。

## 验证范围与已知限制

已运行核心回归、快照脚本行为测试（含与已有状态栏串联）、Release 桌面构建、中文和英文的全页面界面冒烟，以及数据来源设置检查。新增检查会确认设置行是有效 JSON，并且指向安装目录中实际存在的脚本。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

状态栏快照只在 Claude Code 运行、状态栏刷新时更新，这份数据只在用 Pro／Max 订阅登录时提供，也不带账号身份。UsageLoom 不会改动 Claude Code 的设置；移动或卸载 UsageLoom 后，请同步修改或删掉 `settings.json` 中的这一行。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
