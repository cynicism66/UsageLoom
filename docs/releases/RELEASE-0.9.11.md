# UsageLoom 0.9.11

## 更新内容

- **设置新增“托盘额度窗口”**：可以选择托盘图标显示哪个额度。
  - 最紧张的窗口（默认）：显示 5 小时和每周额度中剩余较少的一个，与之前的行为相同。
  - 5 小时／每周：固定显示该窗口。这个窗口没有数据时显示灰环，不换成另一个窗口的数字。
  - “托盘额度来源”选“最紧张的来源”时，按这里选定的窗口比较 Codex 和 Claude。
- **托盘悬停说明更简短**：去掉“非官方本地快照”字样。设置页的“托盘额度来源”说明仍写明数据是非官方本地快照。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增窗口选择检查：默认最紧张、固定 5 小时或每周、固定窗口缺数据时不借用另一个窗口、已过重置时间的窗口、最紧张来源按所选窗口比较。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：设置默认值，保存后重新进入页面和重启应用仍保留；悬停说明中来源后紧跟额度窗口。

托盘图标和悬停说明的最终效果只经自动检查，未在真实任务栏上目视确认。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
