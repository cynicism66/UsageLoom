# UsageLoom 0.7.3

## 本次更新（相对于 0.7.2）

- 修复周容量采样已观察到额度下降，却持续显示 `0/6` 的进度提示：未成段的下降也纳入显示，可按 `1/6 → 2/6 → 3/6` 更新。
- 提示中分别列出已确认、待确认百分点，以及有效区间数量。进度表示观察到的下降，不代表全部通过采样校验。
- 保留每段至少 3 个百分点、后续至少 2 分钟快照与日志确认的规则；待确认部分不参与估算或归档。显示估算仍需足够有效样本。
- 未成段进度基于保存的额度快照重新计算，不需要清空数据库或重新采样；保留账号、套餐与重置周期隔离。
- 更新简体中文和英文提示，补充未成段进度、确认后不重复累计及额度回落后的基准检查。

## 下载与升级

- `UsageLoom-0.7.3-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.7.3-win-x64.zip`：自包含免安装版，解压运行。
- 更新清单与 SHA-256 校验文件随包提供。
- 用户数据仍保存在 `%LOCALAPPDATA%\UsageLoom\user-data`，不要删除该目录。

## 已知限制

- 本次仅修复采样进度展示，不改变用量计价或有效样本门槛，估算不是官方额度金额。
- 此版本没有修复此前遇到的 Windows Installer `1926 / 5`、`Config.Msi` 权限错误；遇到该错误时不要反复安装或删除回滚目录，应先处理未完成安装及权限问题。
- 自动测试不代表已经在干净 Windows 系统完成实际 MSI 升级验收。
