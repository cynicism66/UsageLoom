# UsageLoom 0.8.24

## 更新内容

- 套餐、缓存来源、主题等下拉菜单的展开面板统一改为不透明纯色背景，并增加清晰边框，去掉毛玻璃透底与纹理干扰。
- 浅色主题使用白色背景，深色主题使用深灰色背景；高对比度模式沿用系统颜色。
- 保留原生选项、选中提示和选择逻辑，不改变设置保存、数据读取或额度计算。

## 验证范围

自动回归检查实际展开面板在浅色、深色及跟随系统主题下的不透明背景、边框和选项保持。系统高对比度及跨屏缩放后的视觉效果尚未完成人工验收。

## 升级

可通过软件内检查更新升级。手动安装请将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
