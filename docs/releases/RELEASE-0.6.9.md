# UsageLoom 0.6.9

## 设置入口与托盘

- 额度速览右下角增加镂空齿轮设置图标，透明背景、鼠标提示，点击直接打开设置。未置顶面板随跳转收起，置顶面板保持显示。
- 设置中的“软件更新”移动到“优先尝试已有登录缓存”之后、“高级实验：独立登录”之前。
- 托盘菜单拆分“详细统计”和“设置”，分别进入概览和设置，不再共用一项。
- 中英文均支持，不改变 Token 统计、账号归属、定价或历史缓存。

## 升级

- 安装版：`UsageLoom-0.6.9-win-x64.msi`。
- 免安装版：`UsageLoom-0.6.9-win-x64.zip`，解压后运行。
- 0.6.8 用户可在“设置 → 软件更新”中检查、下载更新并重启；手动升级时先从托盘退出旧版。
- 用户数据继续保存在 `%LOCALAPPDATA%\UsageLoom\user-data\`，升级无需删除或重新采样。
- 发布包含 `update.json` 和 `SHA256SUMS.txt`，供应用内更新与下载校验使用。

## 验证与限制

- 137 项核心测试通过，中英文启动、设置/统计快捷导航和重复切页检查通过。
- MSI 资源、快捷方式和 ZIP 文件清单检查通过；未执行干净系统实际安装验收。
- 安装包尚未签名，Windows 可能显示安全提示。
