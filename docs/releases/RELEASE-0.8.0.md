# UsageLoom 0.8.0

## 本次更新（相对于 0.7.10）

- 将 ⓘ 采样说明弹窗的文字明确设为 12 DIP，减小字号；实际像素大小随 Windows 显示缩放变化。
- 根据窗口可用宽度设置内容宽度，文字自动换行，并为弹窗内边距预留空间，避免紧凑窗口中的横向溢出。
- 禁用该说明弹窗的横向、纵向滚动条。
- 托盘小窗与详细额度页共用此样式，保留点击 ⓘ 查看说明、点击外部或 Esc 关闭，以及刷新时更新内容的行为。

## 范围与升级

- 本版仅调整采样说明弹窗的字号和布局，不改变 Token 统计、账号归属、采样算法及确认门槛，不删除用户历史数据。
- 不包含归属变更后重算同步、托盘小窗展开抖动或 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）的修复。
- 安装包静态检查不代表干净 Windows 系统上的实际升级验收。

## 下载

- `UsageLoom-0.8.0-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.8.0-win-x64.zip`：Windows x64 便携版。
- 随附应用内更新清单 `update.json` 和 SHA-256 校验文件。
