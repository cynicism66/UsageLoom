# UsageLoom 0.7.4

## 本次更新（相对于 0.7.3）

- 修复启动后已有采样进度暂时显示为 0、并出现旧版采样提示的问题。此前必须等待启动后第一次五分钟批量计算才能恢复显示。
- 首次成功查询额度后，立即恢复同账号、同套餐、同重置周期的已保存有效样本，包括尚未达到最终估算门槛的 `3/6、1 段`。
- 恢复后可继续显示新增的待确认百分点；待确认部分仍不参与估算。
- 对缓存版本、价格目录、时间和数值进行校验；切换账号、套餐、重置周期或额度回升时，不将不匹配的旧样本作为当前进度。
- 后台仍按五分钟批量计算，不增加持续重算，也不修改现有用量数据库。

## 下载与升级

- `UsageLoom-0.7.4-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.7.4-win-x64.zip`：自包含免安装版。
- 随附更新清单和 SHA-256 校验文件。用户数据仍保存在 `%LOCALAPPDATA%\UsageLoom\user-data`，请勿删除此目录。

## 验证与已知限制

- 核心回归测试 139 项通过，覆盖启动恢复部分有效样本、进度继续增长及账号/套餐/周期隔离。
- 未成段记录仍需后续快照和日志确认；此次不降低有效估算门槛。
- 本次不修复此前 Windows Installer `1926 / 5`、`Config.Msi` 权限错误；遇到该错误应先处理未完成安装及权限问题，不要反复重装或删除回滚目录。
- 自动检查不代表已完成干净 Windows 系统上的实际 MSI 升级验收。
