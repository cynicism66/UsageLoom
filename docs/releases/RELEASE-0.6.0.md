# UsageLoom 0.6.0

本版重点是后台计算、状态透明度、Token 归属处理和 Windows 发布检查。包含此前本地 0.5.7、0.5.8 的改动。

## 1. 后台计算与清理

- 在线额度快照和本地日志仍照常采集；有变化时每 5 分钟批量计算一次周容量，不因打开托盘面板重复计算。
- 周容量重算、计价和配对明细保存移到后台；清理与计算互斥，避免同时操作同一份配对历史。
- 同时只运行一项周容量计算。计算期间发生扫描、账号、套餐、额度快照或设置变化时，旧结果不覆盖当前显示，下一批重新计算。
- 退出软件会取消配对计算，并等待计算、清理结束。没有新增数据时跳过批量计算。
- 自动清理每天最多执行一次，保留至少 30 天快照和配对明细；为保证完整周期，可能保留更久。没有可靠周期边界时不强行删除。
- 清理前保留对应估算结果。Token 历史、账号归属、估算历史与原始日志不在自动清理范围；SQLite 空闲页复用，不每日压缩数据库。

## 2. 计算状态与手动操作

入口：**设置 → 每周容量估算**。

显示上次计算时间、下次批量检查时间，以及等待索引、等待有效额度、后台计算、完成或失败状态。“立即计算”可以跳过五分钟等待，但不能跳过启用开关、有效账号额度及日志索引要求。

上次计算时间是本次运行中完成计算的时间；跨重启的有效估算仍从历史恢复，并保留历史采样时间标识。下次检查不等于保证产出新估算：样本仍须达到至少 5 个百分点、2 段等有效条件。

美元是 **API 等价估算**，不是官方美元余额或订阅承诺。结果受计价覆盖率、模型组合、日志延迟、额度取整及其他设备消耗影响。没有有效新样本时沿用带时间的历史参考，不把历史样本混入当前周期。

## 3. Token 归属查看与确认

入口：**概览 → 选择时间范围 → 查看与确认 Token 归属**。

1. 选择待处理日期，核对未归属记录数和 Token 总量。
2. 面板同时列出当前范围的其他账号和缺少时间的数量，这两类不会合并。
3. 确认预览记录确实属于当前账号后，勾选声明并确认。
4. 程序重新检查登录状态与预览记录，自动备份数据库，再以事务写入 `user-confirmed` 归属；重复或已变化的预览会拒绝，需要重新打开确认。

未归属的准确含义是缺少连续登录证据。软件未运行、启动和账号核验空档都是可能原因；旧日志没有足够证据时，程序不会声称已经确定是哪一种，也不会把它当成“另一个账号”。

确认仅限所选范围内预览到的记录，之后新出现的记录不被顺带合并。原始日志不修改；独立确认记录支持可识别事件在重建后恢复，但身份、来源、时间或 Token 发生变化时不会强行套用。

备份位置：`%LOCALAPPDATA%\UsageLoom\user-data\backups\attribution-*.sqlite`。备份含本机用量和账号指纹，不要公开上传；本版不自动删除这类备份。尚无图形恢复入口，恢复前应退出软件并保留现有数据副本。

补归属后，下次批量计算重算仍保留快照的可配对区间，不重复累计。缺少快照、跨重置、跨套餐或已清理的旧区间不能强行反推容量。

## 4. Windows 自动验证

新增 Windows 工作流，在 push/PR 后运行 .NET 核心与存储测试，构建自包含桌面程序，生成并检查 MSI 与 ZIP。验证产物保留 7 天，与正式 Release 附件分开；推送本身不会自动发布版本。

回归覆盖数据迁移、事务回滚、估算恢复、时间配对、归属确认及重建保留、旧结果隔离、取消、双语资源等。

发布前本地验证：121 项 C# 回归、14 项 Node 测试、英文 10 个 UI 启动/导航场景及中文个性化/空数据场景通过；MSI 结构检查通过。测试环境 Explorer 托盘不可用，因此不把自动启动日志视为真实托盘验收。

## 下载与升级

- `UsageLoom-0.6.0-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.6.0-win-x64.zip`：自包含免安装版，解压后运行 `UsageLoom.App.exe`。
- `SHA256SUMS.txt`：附件完整性校验。

先从托盘退出旧版再升级。MSI 和 ZIP 默认共用 `%LOCALAPPDATA%\UsageLoom\user-data\`，不要删除该目录。无需为升级重新采样；旧版没有保存的快照无法补造。

## 已知限制

- 安装包尚未签名，可能触发 Windows SmartScreen 提示。
- 自动构建和 UI 导航测试不等同于干净 Windows 安装、多屏/DPI、真实托盘及真实账号端到端人工验收。
- 未承诺首 Token 延迟、请求成功率或官方美元余额；本版没有加入这些无法从现有数据可靠推出的指标。
