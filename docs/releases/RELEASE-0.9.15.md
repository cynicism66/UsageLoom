# UsageLoom 0.9.15

## 更新内容

- **找到新版 Claude 桌面版迁移后的数据目录**：新版 Claude 桌面版把本机数据从 `%APPDATA%\Claude` 迁到了 `%LOCALAPPDATA%\Claude-Data\` 下的子目录，旧目录里只留下一个迁出标记。UsageLoom 原来只在旧位置自动查找，找不到桌面版的额度缓存，Claude 额度因此停止更新。现在自动查找会同时检查新位置，并跳过带迁出标记的旧目录。
  - 设置里手动填写过 Claude 数据目录的，请改为留空或填写新目录。

## 已知限制

- 在 Claude 桌面版的 Code 标签页中使用 Claude Code 时，桌面版不运行 `settings.json` 里配置的状态栏命令，附带的状态栏快照脚本不会更新。这时 Claude 额度只能来自桌面版自己的缓存；缓存里没有当前额度响应时，只显示百分比历史，不显示重置时间，托盘图标也不使用这类数据。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增数据目录查找检查：旧位置、新位置、两处都有时要求手动选择、旧目录有迁出标记时只采用新位置、`Claude-Data` 下的说明文件不算目录。
- Release 桌面构建、全页面界面冒烟、托盘小窗与数据来源设置检查。
- 本机只读核对：自动查找只找到新位置的一个目录，可以读到额度快照。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
