# UsageLoom 0.8.14

## 更新内容

- 修复覆盖安装时因权限不足而反复弹出 `Config.Msi` 回滚文件安全设置错误的问题：安装前检查实际管理员权限，权限不满足时提前停止。
- MSI 更新请求 Windows UAC 授权；取消授权时不替换程序文件，原应用以正常权限重新打开。
- 保持当前用户安装范围、原安装目录与事务回滚保护，并校验提权前后的 Windows 账号一致。
- 不更改用量记录、账号归属、设置、Claude 缓存或额度采样历史。

## 从旧版升级

1. 下载本页的 `UsageLoom-0.8.14-win-x64.msi` 和 `UsageLoom-install.cmd`，放在同一个文件夹。
2. 从托盘退出 UsageLoom，然后双击 `UsageLoom-install.cmd`，确认当前 Windows 账号的 UAC 授权。
3. 安装入口会核对 MSI 的 SHA-256，并沿用已登记的安装位置。完成后正常启动 UsageLoom。

旧版自带的更新脚本还不会请求 UAC，因此首次升级到本版请使用上述安装入口；不要连续重试旧版应用内安装。更新到本版后，后续应用内 MSI 升级会自动请求授权。

请直接双击安装入口，不要用“以其他用户身份运行”。如果 UAC 必须输入另一账号的凭据，安装会停止，以免改变安装归属；此时可使用 ZIP 便携版。直接打开 MSI 而未提权时，也会提前给出提示。

无需删除 `Config.Msi`、重置磁盘权限或卸载已经完整安装的软件。ZIP 便携版仍可直接解压使用。[安装与卸载说明](https://github.com/cynicism66/UsageLoom/blob/main/docs/INSTALLATION.md)

## 验证范围

包含隔离更新回归、MSI 结构与前置检查，以及临时 Windows CI 环境中独立测试产品的安装、覆盖升级和卸载验证。未在用户真实磁盘上重新执行覆盖安装；系统 ACL 损坏或安全软件拦截仍可能导致安装失败，需结合安装日志诊断。
