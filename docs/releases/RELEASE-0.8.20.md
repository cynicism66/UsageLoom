# UsageLoom 0.8.20

## 更新内容

- 在“设置 → 数据来源”中，Codex 与 Claude 使用统一布局和独立的“启用数据源”开关，可只开其中一个、同时开启或全部关闭。
- 停用 Codex 会停止日志采集、额度查询、账号续验、采样和通知，并隐藏 Codex 的卡片与统计；保留已有设置和历史数据。升级旧配置时 Codex 默认继续启用。
- 重新启用后先获取新快照、重新建立连续账号观察。停用期间的日志仍可补扫，但不会自动归属或用于跨停用区间估算。
- 边界写入失败时暂停恢复并自动重试，重启后仍保留保护；开关保存失败时恢复原状态。
- 数据源正在保存时拦截其他入口的交叉保存和授权，避免未保存的路径被带入当前配置。
- Claude 停用时停止缓存读取并隐藏卡片，保留目录和来源配置，不会关闭 Claude 软件或删除其文件。

## 升级

可通过软件内检查更新升级。手动安装请将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。

## 验证范围

覆盖旧设置默认值、两个保存入口、独立开关组合、切页与重启、保存失败与交叉保存保护、停用采集入口、持久化边界恢复、同账号恢复时的用量归属以及页面和安装升级回归。测试使用隔离数据，不修改用户真实配置或安装。
