# UsageLoom 0.8.41

## 更新内容

- “设置 → 数据来源”中的 Codex 和 Claude 各增加“在界面中显示”开关，与“启用数据源”相互独立：
  - 只关闭“在界面中显示”：该来源从界面上隐藏，后台仍照常读取和统计用量，重新打开即可看到完整数据。
  - 关闭“启用数据源”：同时停止该来源的读取。
  - 两种方式都保留历史数据。
- 隐藏或停用的来源不再出现在总览、当前额度、统计页、托盘小窗和托盘图标中；隐藏的 Codex 也不再发送额度通知。
- 只显示一个来源时，概览、模型与项目、Session 明细页去掉 Codex／Claude 切换按钮，直接显示该来源的用量；两个都显示时保留切换。
- 现在只用 Claude 的话，关闭 Codex 的“启用数据源”或“在界面中显示”即可。

## 验证范围与已知限制

已运行核心回归、Release 桌面构建、中文和英文的全页面界面冒烟，以及数据来源设置检查。新增的界面检查覆盖只显示 Codex、只显示 Claude、都隐藏和停用等组合，并确认隐藏不会停止读取，且开关状态在保存后保留。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

Claude 的用量统计来自本机 Claude Code 的会话记录；Claude 桌面版和网页聊天在本地没有 Token 记录，只能显示额度。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
