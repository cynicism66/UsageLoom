# UsageLoom 0.8.1

## 更新内容

### 保存普通设置不再清空采样

- 保存刷新频率、通知或外观等普通设置时，保留当前账号上下文、已确认样本和采样起点。
- 不再为了普通设置保存而无条件重启后端、清空额度或记录强制断点。
- 日志路径、后端程序或登录模式等关键来源变化仍建立隔离边界，并记录脱敏诊断信息。

### 完善断网后的自动恢复

- 查询失败按实际失败类型记录，不再因为缺少账号上下文而误标为主动重置。
- 明确的查询中断中，暂时缺少身份并不等于账号切换。计算过程保留用于比对的上下文，恢复时仍须核对成功查询得到的实际账号、套餐、价格目录及周期。
- 可恢复的已确认样本继续保留；未完成区间只有通过连续性核验才续接，不为凑进度强行合并。
- 说明框增加未通过连续性核验的中断区间提示，日志记录区间时间和未通过原因；后续证据更新时重新计算。
- 真正的账号切换、主动重置与无法证明可续接的旧硬边界仍保留隔离。

## 验证与数据安全

- 核心测试 143/143 通过，覆盖设置来源比较、连续断网缺少身份、身份不匹配、长间隔恢复及归属证据重新核验。
- 升级不删除原始日志或 Token 记录，不自动撤销所有历史强制断点。
- 本版不内置任何用户的账号、数据库或针对个人历史的修正记录，也不包含临时 audit 核验工具。
- 历史断点是否可恢复仍取决于现存证据；不能保证所有历史缺口均可自动续接。

## 下载与已知限制

- `UsageLoom-0.8.1-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.8.1-win-x64.zip`：Windows x64 便携版。
- 随附应用内更新清单和 SHA-256 校验文件，升级保留用户数据。
- 不包含托盘小窗展开抖动或 Windows Installer `Config.Msi` 权限错误（1926 / 错误 5）的修复。安装包静态校验不等于干净 Windows 系统上的实际升级验收。
