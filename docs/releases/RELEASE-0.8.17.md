# UsageLoom 0.8.17

## 更新内容

- Claude 桌面版设置移入“数据来源”，与 Codex 路径集中管理，打开一个分组即可查看两者配置。
- 数据来源内部使用 Codex、Claude 桌面版两个标题区分，不再单独设置 Claude 顶层分组，也不增加嵌套折叠操作。
- 保留 Claude 开关、目录、缓存来源和两个读取按钮；已有配置无需重新填写，用量记录和额度计算不受影响。

## 升级

可通过软件内“检查更新”升级并确认 UAC。手动安装时，将同版本 MSI 与 `UsageLoom-install.cmd` 放在同一目录，从托盘退出软件后双击安装入口。无需卸载或清理数据。

## 验证范围

包含核心回归、设置分组层级、Claude 两个保存入口、页面重新进入与进程重启回归，以及桌面页面和打包检查。未修改用户现有安装或真实数据。
