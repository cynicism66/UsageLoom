# UsageLoom 0.8.40

## 更新内容

- 修复英文界面在中等窗口宽度下，概览、模型与项目、Session 明细页标题栏的 Codex／Claude 来源切换按钮被长副标题挤压、显示不全的问题。空间不足时副标题改为换行，切换按钮和右侧操作按钮保持完整；窄窗口和中文界面的布局不变。
- Claude 接入说明移至 `docs/claude-desktop-quota.md`，README 与隐私说明中的链接已同步更新。

## 验证范围与已知限制

已运行核心回归、Release 桌面构建，以及中文和英文的全页面界面冒烟。新增的界面检查会在多种标题栏宽度下确认来源切换按钮完整显示。真实拖拽窗口、多屏与 DPI 切换仍需在桌面环境人工检查。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
