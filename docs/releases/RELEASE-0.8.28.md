# UsageLoom 0.8.28

## 更新内容

- Claude 概览新增额度历史，支持近 1／7／30 天筛选、5 小时及每周额度趋势、已知重置周期和最近观测明细。
- 导入可读取的本地额度历史，并独立保存最近 31 天的快照。重复读取不会增加重复记录，切换来源不混用历史，不影响 Codex 数据与计算。
- 明确显示观测时间、来源、缓存新旧和数据缺口。缺少重置时间时展示观测点；只有同一已知周期、间隔不超过 15 分钟且百分比未回退的相邻快照才连线并计算百分点增长。
- 冲突、跨周期和长间隔不推算用量；保存失败给出提示，读取失败不把旧快照冒充当前额度。
- 模型与项目、Session 页面提供 Claude 额度历史入口。Token、请求、Session、模型与费用明细尚未接入，不会通过额度百分比伪造。

## 使用与限制

更新后启用 Claude 数据源，在“概览”选择 Claude 即可查看。需要新快照时，请先在 Claude 中刷新 Usage，再到 UsageLoom 重新读取。无需额外登录，不读取登录凭据或聊天正文，不主动请求 Claude 网络接口。

每个来源最多保留最近 31 天、4 万条窗口记录。图表最多显示最近 600 条，统计使用整个所选时段。所示增长只代表可核验的部分观测，不是完整消费账目；缓存来源不能证明当前登录身份，换号后请核对。未取得的历史无法补回。

## 验证范围

包含核心回归、隔离模拟数据下的桌面检查与安装包验证。未在用户电脑执行覆盖安装，也未以用户真实数据进行人工逐页验收。

## 升级

可通过软件内检查更新升级。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
