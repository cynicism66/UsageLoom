# UsageLoom 0.8.2

## 更新内容

### 重启推定记录可经核验参与估算

- 不再仅凭 `restart-inferred` 标签永久排除整段采样。
- 读取正常退出与重启时保存的审计记录，核对事件 ID、时间范围和账号归属。
- 仅接受有充分证据的短时间重启：审计区间不超过 15 分钟，前后额度快照在限定时间内，账号、套餐、价格目录和周周期一致，并有后续快照和索引确认。
- 额度回退、硬边界、证据缺失或身份不一致时不放行。原始事件的归属标签不改，只在计算副本中使用核验结果。

### 修复反复断网造成的确认中断

- 明确的查询失败不再直接清除后续快照的确认链，避免历史区间长期停留在等待确认状态。
- 恢复配对仍检查实际账号、周期、用量完整性和中断条件，不跳过真实的账号切换或主动重置边界。
- 更新中英文归属说明及诊断日志，明确推定记录需要额外核验，而不是一律排除或一律接受。

## 验证与数据安全

- 核心测试 145/145 通过，覆盖缺失审计、事件不匹配、账号不一致、时间限制、后续确认不足、硬边界和反复查询失败。
- 实际数据库副本复算恢复为 15 个已确认百分点、5 段样本，重复事件数为 0；这是该核验数据的结果，不是所有用户的固定进度。
- 不修改原始日志，不删除 Token 记录，不内置任何用户数据库或临时核验工具。
- 升级后完成额度查询及日志索引，程序会按现存证据重新计算；无法证明安全的历史区间仍保留排除。
