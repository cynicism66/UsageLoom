# UsageLoom 0.8.4

## 更新内容

### 修复额度超时造成的归属空档

- 将扫描器使用的账号身份与额度查询的新鲜度分离。账号读取成功后，即使后续额度请求超时，也不会立即把新增 Token 记为未归属。
- 在账号确认仍有效时，恢复后的第一轮扫描不再因上一轮额度失败额外产生归属空档。
- 增加脱敏账号确认日志，便于区分身份确认与额度查询状态，不包含账号 ID、邮箱或登录凭据。

### 保留必要的身份保护

- 账号确认仅在当前进程内生效，要求来源一致，最长有效期为 5 分钟；不从旧额度缓存恢复身份。
- 身份失效、明确换号、认证失败或来源切换时停止沿用旧身份，并取消使用旧身份的进行中扫描。
- 来源切换后再次清除旧请求可能留下的身份，避免旧查询完成时恢复过期上下文。
- 未登录、缺少稳定身份、确认过期或系统时间回拨时，记录仍会保留，但不会强行归属。

## 验证与升级说明

- 153 项核心测试通过，覆盖独立身份确认、有效期、来源隔离、额度超时、恢复首轮扫描及真实账号变化。
- 应用构建与隔离数据启动检查通过；不代表已经完成干净系统上的安装升级验收。
- 不修改原始日志、不删除 Token 记录，也不会自动批量认领既有未归属历史。已有记录仍可通过应用内归属确认流程处理。
- 安装包不包含用户数据库、日志或本地核验工具。

## 下载与限制

- `UsageLoom-0.8.4-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.8.4-win-x64.zip`：Windows x64 便携版。
- 提供应用内更新清单及 SHA-256 校验文件。
- 长时间无法确认身份时，仍可能产生未归属记录，这是安全边界，不代表 Token 丢失。
- 本版不包含托盘展开抖动或 Windows Installer `Config.Msi` 权限错误的修复。
