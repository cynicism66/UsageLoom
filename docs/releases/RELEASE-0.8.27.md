# UsageLoom 0.8.27

## 更新内容

- 概览顶部并排展示已启用 AI 的额度卡片，套餐、读取方式、更新时间、重置倒计时与估算归入对应卡片。窄窗口自动改为上下排列。
- 下方使用 Codex／Claude 标签切换统计区，概览、模型与项目、Session 明细保持相同的 AI 选择。切回 Codex 时保留日期、搜索与排序；趋势跳转保留日期与 AI。
- Claude 暂未接入 Token、请求、Session、模型与项目明细及估值统计，页面明确说明能力范围，不把未采集数据显示成 0，也不会显示 Codex 的数据。
- 标签只切换查看对象，不启停数据源。未启用的 AI 显示提示，已有设置和历史记录保持不变。
- Codex 的采集、通知、计算设置和维护操作明确标注归属；归属确认、修复、清除计算历史、重新采样弹窗说明仅处理 Codex，不影响 Claude。
- 本次不新增 Claude 明细采集，不改变计价、额度估算或账号归属算法。

## 升级

可通过软件内检查更新升级。手动安装请将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。

## 验证范围

已执行核心回归和隔离模拟数据下的桌面自动化检查，覆盖 AI 切换、筛选保留、中英文、窄窗口、设置保存及小窗回归。未在用户真实数据环境中进行人工逐页验收，也未在用户电脑执行覆盖安装。
