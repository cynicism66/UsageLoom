# UsageLoom 0.9.2

## 更新内容

- **超大 Claude Code 会话不再被跳过**：
  - 以前单个会话日志超过 128 MiB 就整份不读。长时间续用的会话（例如开了好几天的项目会话）里的用量因此缺席 Token 统计，每周容量参考也一直显示“本机 Code 日志不完整”。
  - 现在只在末尾追加的会话从上次读到的位置接着读，不再每次重读整个文件；单个文件上限放宽到 1 GiB。文件被改写或截断时，仍会整份重读。
  - 以开发者本机为例：首次读取约 3 秒，之后每次刷新只读新增部分，约 10 毫秒。
- **托盘小窗卡片右侧不再留白**：
  - 以前窗口高度按固定值估算，比实际的标题栏、按钮和边距少十几个像素，卡片被等比缩小，右侧空出一条。
  - 现在按实际布局计算高度，卡片铺满宽度。第一次打开时窗口可能会在显示后立即微调一次高度。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增测试覆盖：
  - 追加时只读新增部分，结果与全量读取一致；
  - 半行补齐后接着读；
  - 改写或截断时整份重读；
  - 小窗高度按实际边距计算。
- Release 桌面构建、中文和英文的全页面界面冒烟，以及数据来源设置检查。
- 小窗检查：新增“卡片未被缩小”的断言。旧版高度计算在这项检查下失败（卡片 332 DIP 被缩到 320），修复后通过；关闭再打开时窗口位置和大小保持不变。

开发者本机的真实 Claude Code 日志只读运行过一次，只统计数量，不输出内容：
- 之前被跳过的 158 MiB 会话现已读入；
- 剩下 2 条 10 月 19 日计数前后矛盾的记录仍按保守规则跳过，它们早于当前周期，不影响估算。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
