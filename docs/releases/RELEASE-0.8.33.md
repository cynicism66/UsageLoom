# UsageLoom 0.8.33

## 更新内容

- Claude 的概览与当前额度卡片新增“每周额度参考估算（实验）”。程序将同一额度来源、同一周周期的连续百分比快照与同期本机 Claude Code Token 日志配对；样本达标时显示同工作负载的 Token／周参考值。模型价格覆盖足够时，还会显示 API 美元等价值。
- 样本不够、重置时间缺失、额度快照过期或本机日志不完整时，卡片会说明原因。额度增长却没有对应本机 Code 活动，或各段比例差异过大时，不显示推算数字。托盘卡片悬停也能看到当前参考状态。

## 使用与边界

在“设置 → 数据来源 → Claude 桌面版”启用本机 Claude Code 日志读取；在 Claude 的 Usage 页更新额度后，返回 UsageLoom 重新读取。可能需要积累多段有效快照。普通 Chat、Cowork、云端 Code、其他设备和旧日志缺口无法完整覆盖；本机日志也不能证明属于当前套餐账号。这个值只是当前工作负载的条件对照，不是 Claude 官方固定 Token 容量、剩余量或订阅账单。卡片上的剩余百分比仍来自 Claude 缓存快照，不由估算改写。

## 验证范围

运行核心回归、中文和英文桌面界面冒烟、安装包结构及发行附件校验。没有在用户电脑执行覆盖安装。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
