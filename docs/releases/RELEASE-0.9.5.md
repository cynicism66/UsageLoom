# UsageLoom 0.9.5

## 更新内容

- **移除 Claude 容量参考估算**：
  - 概览、当前额度和托盘小窗不再显示 Claude 的“5 小时／每周额度参考估算”、采样进度和原因说明。
  - 原因：Claude 的额度快照只有百分比，本机 Claude Code 日志看不到网页、手机和其他电脑上的用量，配对外推的结果不可靠；还要长时间采样，大多数时候只能显示“样本不足”。
  - Claude 卡片保留剩余额度、重置时间、节奏提示和快照时间；托盘小窗的 Claude 卡片相应变矮。
  - “设置 → 每周容量估算”中的 Claude 一栏改为说明不提供容量估算。Codex 的每周容量估算不受影响。
  - 不涉及数据迁移：Claude 额度历史、本机 Claude Code Token 统计和 API 等价值照常保留。
- **125% 等非整数缩放下的托盘小窗**：
  - 0.9.2 起小窗高度按实际布局计算，但在 125% 这类缩放下，高度会被取整到整像素，卡片仍可能被缩小约 1 像素，右侧留下细缝；显示器变化后恢复的窗口也可能差 1 像素。
  - 现在计算高度时多留 2 DIP 余量，并忽略 1 像素以内的测量波动，卡片铺满宽度，恢复后的窗口大小保持一致。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
