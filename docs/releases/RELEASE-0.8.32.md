# UsageLoom 0.8.32

## 更新内容

- Claude 统计的“自定义”日期筛选与 Codex 统一：两个日期框都显示“开始／结束”，日期采用 `yyyy-MM-dd` 格式，并移除右侧重复的日期范围摘要。
- 日期框在窄窗口中会纵向排列，避免拥挤；新增界面检查防止两处格式再次分叉。

## 验证范围

运行核心回归、桌面界面冒烟和安装包结构检查。没有在用户电脑执行覆盖安装。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
