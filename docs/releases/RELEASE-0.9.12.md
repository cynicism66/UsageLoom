# UsageLoom 0.9.12

## 更新内容

- **设置“容量估算（实验）”里的 Codex 部分可以单独折叠，默认收起**：展开这一节后，先看到一行“Codex”，点开才显示开关、采样状态和各项操作按钮，页面不再被一大块内容占满。
  - 从额度卡片跳转到估值依据时，会自动展开到对应位置。
  - 重新进入设置页时恢复收起。

## 验证范围与已知限制

已运行以下检查：
- 核心回归。
- Release 桌面构建、中文和英文的全页面界面冒烟、托盘小窗、个性化设置与数据来源设置检查。
- 新增界面检查：Codex 部分默认收起；手动收起后，跳转到估值依据仍能逐层展开并显示内容。

安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
