# UsageLoom 0.7.0

## 日期筛选栏修复

- 修复概览顶部出现空白卡片、“日 / 近 7 天 / 周 / 月 / 自定义”按钮消失的问题。
- 原因是切页时移除了共享筛选控件，但返回页面时数据未变化，渲染缓存跳过重建，留下空容器。
- 现在切页时同步使布局缓存失效，返回概览、模型与项目或 Session 明细时重新挂载筛选控件，保留原有日期选择。
- 无需清空缓存、重建数据库或重置估算；Token 统计、账号归属和周容量历史不受影响。

## 回归验证

- 增加导航后的筛选栏视觉父级、实际宽高及按钮数量检查，覆盖数据不变时往返设置、额度、诊断页和统计页。
- 显式管理共享筛选控件的容器，避免 WinUI 卸载旧页面时找不到父级而重复挂载。
- 138 项核心测试通过；中英文有数据和空数据场景检查筛选栏的挂载和可见性。
- 保留原有更新检查频率选项及手动更新功能。

## 下载与升级

- `UsageLoom-0.7.0-win-x64.msi`：Windows x64 安装版。
- `UsageLoom-0.7.0-win-x64.zip`：免安装版，解压后运行。
- 可在旧版“设置 → 软件更新”中检查并确认升级；手动升级前请从托盘退出旧版。
- 用户数据继续保存在 `%LOCALAPPDATA%\UsageLoom\user-data\`，请勿删除该目录。
- 附带 `update.json` 与 `SHA256SUMS.txt`。安装包尚未签名；包结构检查不等同于干净系统实际安装验收。
