# UsageLoom 0.8.15

## 更新内容

- 修复开启 Claude 后点击右上角“保存设置”，离开设置再进入却恢复关闭的问题。右上角和 Claude 区域内两个保存入口都会保存开关、数据目录与缓存来源，重启后继续保留。
- 后台刷新不会覆盖尚未保存的来源选择；更换 Claude 数据目录时清除旧来源，避免串用不同目录的设置。
- 普通保存不再重置未改变的 Claude 快照；非法目录或写入失败会保留原 Claude 配置。
- 不改变 Codex Token、账号归属、计价与额度采样规则。

## 使用与升级

安装后在“设置 → Claude 桌面版”打开“显示 Claude 桌面版额度”，点击右上角“保存设置”即可。默认仍为关闭，不会擅自启用。

0.8.14 用户可以使用应用内更新并确认 Windows UAC。手动安装时，将本页的 `UsageLoom-0.8.15-win-x64.msi` 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出软件后双击安装入口。更早版本建议使用该手动入口。无需卸载或清理本地数据。

Claude 仍只读取本地额度缓存，不额外登录或主动发送额度请求；缓存较旧时需先在 Claude 的 Usage 页面刷新，再回 UsageLoom 重新读取。

## 验证范围

包含实际 WinUI 保存按钮、退出设置再进入、独立进程重启、目录变化、来源选择、非法路径和配置写入失败的隔离回归；不操作用户现有安装与真实数据。
