# UsageLoom 0.9.0

## 更新内容

- **Claude 5 小时容量参考（实验）**：Claude 额度卡片在每周参考之外，新增 5 小时参考：
  - 把同一个 5 小时周期内连续的额度快照，与同期本机 Claude Code Token 配对，外推“同样工作量下 5 小时大约能用多少本机 Code Token”。
  - 5 小时额度涨得快，接入 Claude Code 状态栏快照后，用一阵 Claude Code 就能出数。
  - 与每周参考使用同样的保护条件：样本不足、额度增长期间有本机日志之外的用量、比例不稳或日志不完整时不出数，并显示具体原因。两个窗口分别计算，互不混用。
  - 概览卡片每行显示一个窗口的结果或原因，点信息图标可查看两者的采样进度；当前额度页分别列出。
- **托盘数字更大**：托盘图标中间的剩余百分比按图标尺寸选用更大的字形。125% 缩放下由 5 像素高增至 9 像素高，其他缩放也相应放大；100% 与 1 位数都不会压住圆环。
- **状态栏转发更快**：Claude Code 状态栏快照脚本先把数据转发给原状态栏，再保存快照，串联的状态栏不再等待写文件。升级后自动生效，无需修改 Claude Code 的设置。
- README 与仓库简介更新为 Codex 与 Claude 双来源的说明。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增测试覆盖：
  - 5 小时参考的配对与周期边界；
  - 与每周窗口互不混用；
  - 托盘数字在各图标尺寸下的高度，以及不压圆环。
- 快照脚本行为测试；
- Release 桌面构建；
- 中文和英文的全页面界面冒烟；
- 数据来源设置检查。

新增的界面检查确认概览同时显示 5 小时与每周两行估算，额度详情两者都有；去掉 5 小时一行后检查会失败。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

容量参考只是本机 Claude Code 工作量的对照，不是 Anthropic 公布的额度或账单。本机日志不能证明属于当前订阅账号，网页、桌面版聊天、云端和其他设备的用量无法计入；同时使用这些渠道时会显示原因而不出数。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
