# UsageLoom 0.7.1

本次说明以已发布的 **0.7.0** 为基准，包含工程结构整理和发布包精简两个阶段的全部改动。0.7.0 已有的日期筛选栏修复、更新检查频率等功能继续保留，不重复计作本版新增功能。

## 工程结构整理

- 将 Dashboard 按公共控件、历史统计、额度、容量估算、设置和诊断拆分为 partial 文件，保留原逻辑。
- JavaScript/MCP 原型集中到 `legacy/codex-plugin`，同步 CI、测试和打包入口。
- 发布说明统一到 `docs/releases`，新增目录指南。
- 打包脚本统一读取 App 项目版本，新常规构建输出统一到 `artifacts/bin` 和 `artifacts/obj`。

## 发布包精简

- 改用官方 Windows App SDK WinUI 组件包，不再通过总包带入未使用的 AI、ML、Widgets、独立 DWrite 和部署组件；不是按文件名手动删除依赖。
- 保留自包含 .NET/WinUI、双语资源和 SQLite，不启用反射裁剪或单文件打包，不要求用户另装运行时。
- 发布目录文件（不计 PDB）从 527 项降至 469 项，体积从 229,003,686 字节降至 175,956,482 字节，减少约 23.2%。
- 构建使用全新临时发布目录，校验后替换输出，旧发布目录保留备份；打包前校验必需依赖、无用组件和更新清单一致性。
- 升级回归覆盖旧版 ONNX、DirectML、AI/Widgets 文件的备份、移除与失败保留；用户自有文件不受影响。
- MSI 从约 71.1 MiB 降至 53.4 MiB；ZIP 从约 87.8 MiB 降至 67.0 MiB。
- 138 项核心测试、全页面检查、英文主题与语言验证及模拟升级回滚通过。未做干净 Windows 实际安装验收；本次网络无法获取 NuGet 漏洞审计数据，默认审计配置未关闭。

## 数据与安装

安装布局、用户数据目录和自动更新协议不变。未删除旧包、诊断副本或用户数据。安装包尚未签名。

- 安装版：`UsageLoom-0.7.1-win-x64.msi`；免安装版：`UsageLoom-0.7.1-win-x64.zip`。
- 可从 0.7.0 的“设置 → 软件更新”检查并确认升级；手动升级前从托盘退出旧版，不要直接把 ZIP 覆盖解压进旧目录，以免留下旧组件。
- 手动使用 ZIP 时解压到新的程序目录，用户数据仍从 `%LOCALAPPDATA%\UsageLoom\user-data\` 读取，无需重新采样。
- 附带 `update.json` 与 `SHA256SUMS.txt`，用于自动更新发现及完整性校验。
