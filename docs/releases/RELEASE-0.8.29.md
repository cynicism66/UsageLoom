# UsageLoom 0.8.29

## 更新内容

- Claude 概览新增本机 Claude Code Token 曲线：今天按小时，近 7／30 天按本地日期汇总；可查看普通输入、输出、缓存读取与缓存写入。
- Claude 的模型与项目、Session 页面接入本机日志汇总。Session 使用匿名标识，不读取聊天标题或正文作为名称。
- 设置增加独立的 Claude Code 日志读取开关与 Home 路径，默认关闭。支持默认 `~/.claude` 和 `CLAUDE_CONFIG_DIR`，也可手动指定本机 Home。
- 流式记录按回复／请求身份去重，处理跨文件副本和子代理父回复重放，避免把缓存写入细分重复计算。文件追加、半行、截断或重写后重新核对。
- 额度百分比历史移入辅助折叠区，已知同周期的相邻有效观测改为阶梯线；详细质量说明收进提示。

## 使用与边界

在“设置 → 数据来源 → Claude 桌面版”启用 Claude 数据源，再启用“读取本机 Claude Code Token 日志”，保存后在概览选择 Claude。

只统计所选 Home 下 `projects` 中仍存在且可识别的本机日志。不保证涵盖普通聊天、Cowork、网页或其他设备；没有日志显示“未发现”，不表示用量为 0。日志可能包含多个账号或 API 用量，不自动归属当前 Pro 账号。Token 不换算为套餐百分比，也不提供 Claude 费用估算。

文件扫描会经过原始 JSONL 字节，但解析跳过正文、代码与工具内容，仅在内存缓存时间、模型、项目、匿名会话标识和用量计数，不保存日志副本、凭据或聊天正文，不上传。源日志被清理后，相应明细将不再包含在统计中。超大文件、不完整记录、缺少可靠身份的记录会被跳过并标明统计不完整。

## 验证范围

使用合成 JSONL 验证解析、去重、缓存分类、损坏与半行恢复、文件重写和取消；桌面使用独立模拟数据检查导航、设置持久化与不同数据源隔离。尚未取得用户当前普通聊天／Cowork 的真实 Token 日志，因此未宣称这些场景已完成实机覆盖。未在用户电脑执行覆盖安装。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
