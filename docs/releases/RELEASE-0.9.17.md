# UsageLoom 0.9.17

## 更新内容

- **补上新型号的 Claude API 价格**：Claude 统计中的“API 等价估算”原来没有收录 Claude Fable 5.2，这部分 Token 不计入金额，趋势图悬停时显示“部分模型未定价”。现在按 2026-11-15 核对的[官方 Claude API 价格](https://platform.claude.com/docs/en/about-claude/pricing)补上（单位：美元 / 百万 Token）：

  | 模型 | 输入 | 5 分钟缓存写入 | 1 小时缓存写入 | 缓存读取 | 输出 |
  |---|---|---|---|---|---|
  | Fable 5.2 | 8 | 10 | 16 | 0.20 | 40 |
  | Fable 5.1 | 10 | 12.50 | 20 | 0.25 | 50 |
  | Fable 5 | 10 | 12.50 | 20 | 1 | 50 |
  | Sonnet 5.5 | 2 | 2.50 | 4 | 0.10 | 10 |
  | Haiku 5.5（提示不超过 10 万 Token） | 0.10 | 0.125 | 0.20 | 0.01 | 0.50 |
  | Haiku 5.5（提示超过 10 万 Token） | 0.50 | 0.625 | 1 | 0.05 | 2.50 |

  Mythos 5.2 / 5.1 / 5 与同版本的 Fable 价格相同，一并收录。Haiku 5.5 按每次请求的提示长度（输入、缓存读取与缓存写入之和）选择价格档。
- **修复 Sonnet 5.5 被按 Sonnet 5 计价**：价格表原来按名称前缀匹配，`claude-sonnet-5-5` 会被当作 Sonnet 5，缓存读取多算了一倍。现在只把带日期后缀的名称（例如 `claude-sonnet-5-20260901`）视为同一型号；以后出现未收录的新型号时，显示为未定价，不套用相近型号的价格。

金额仍是按公开 API 价格折算的参考值，不是 Pro／Max 订阅的账单。

## 验证范围与已知限制

已运行以下检查：
- 核心回归，新增价格检查：Fable 5.2 各项单价与金额、Sonnet 5.5 与 Sonnet 5 的缓存读取价不同、日期后缀仍匹配、未知小版本不匹配、Haiku 5.5 在 10 万 Token 两侧分别取两档价格。
- Release 桌面构建、全页面界面冒烟与设置检查。
- 本机只读核对：本机 Claude Code 日志中的型号全部有价格。

快速模式、区域推理（`inference_geo`）、批处理和工具费仍不计入。安装包结构和升级规则经自动检查；真实安装与从旧版升级未在实机验证。

## 升级

可在软件内检查更新。手动安装时，将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
