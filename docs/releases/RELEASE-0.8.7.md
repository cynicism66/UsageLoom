# UsageLoom 0.8.7

## 更新内容

### 当前周期不再背负旧周期的中断提示

- 中断警告只显示与当前账号、套餐、定价版本和主周额度周期匹配的问题。
- 旧周期记录保留用于诊断，不再被当成当前采样故障；当前周期确有中断时显示原因与发生时间。
- 支持提前重置、周期短暂切换后返回、重置时间小幅漂移等情况；账号或数据来源的明确隔离边界继续生效。

### 采样状态说明更准确

- 进度显示“已确认”和“未计入”，不再把所有未完成部分统称为“待确认”。
- 单段不足 3 个百分点时明确显示还差多少，不会误导为再等两分钟就能完成。
- 达到门槛后分别说明等待后续快照、等待日志完整或等待核验结果；两分钟是快照间隔要求，不是完成倒计时。
- 新额度到达时不会复用旧端点证据，提前重置、额度回退或周窗口变化也会及时更新展示。

### 历史参考与当前采样分开显示

- 额度卡、小窗说明和设置页明确标识历史参考金额，并单独展示当前周期采样。
- 历史生成时间明确不是最新记录时间，避免误以为本机用量已经停止记录。
- 当前周期达到有效估算门槛后，自动显示当前结果。

## 验证与数据安全

- 175 项核心测试通过，覆盖周期切换、提前重置、额度回退、短暂切回、账号隔离、各采样阶段和历史参考切换。
- 同一只读数据库副本的新旧版本回放，样本、区间、历史估算及待配对起点的校验摘要完全一致；回放未包含运行中才有的内存扫描不确定性状态。
- 本版不修改原始日志、Token 或归属，不清除已有历史，也不放宽样本门槛或强行合并缺少连续性证据的区间。
- 自包含程序、隔离中英文界面启动与导航、MSI 结构、便携包清单和更新回滚检查通过；未执行真实安装升级，不代表干净系统安装验收。
