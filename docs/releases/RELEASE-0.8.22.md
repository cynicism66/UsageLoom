# UsageLoom 0.8.22

## 更新内容

- Claude 小窗增加 5 小时和每周剩余额度进度条，与 Codex 使用一致的进度条样式；缺失或已过重置时间的窗口显示淡色空轨道。
- 在“设置 → 数据来源 → Claude 桌面版”增加套餐类型选择。套餐在概览、当前额度及小窗显示，并明确标注“手动设置”。默认未设置，可选择 Free、Pro、Max、Max 5X、Max 20X、Team 或 Enterprise。
- 手动套餐仅用于显示，不参与额度计算。切换账号、缓存来源或套餐后请重新核对；不会自动推断或把所有用户设为 Pro。
- 保留固定布局，额度刷新或状态变化时不重新创建小窗进度条，不改变数据读取方式。

## 升级

可通过软件内检查更新升级。手动安装请将同版本 MSI 和 `UsageLoom-install.cmd` 放在同一目录，从托盘退出 UsageLoom 后运行安装入口并确认 UAC。无需卸载或清理数据。
