# UsageLoom 0.8.9

## 更新内容

- 将完整采样说明、估值依据与工作负载构成移至“设置 → 每周容量估算（实验）→ 估值依据与工作负载”，在设置页内折叠显示，不再打开长详情对话框。
- 精简额度卡与托盘小窗的 ⓘ 说明，仅保留估值、简短采样状态和“在设置中查看详情”入口；模式证据、条件估算及模型／模式／思考强度构成统一在设置中查看。
- 点击详情入口后自动打开主窗口设置，定位并展开对应区域；小窗保持原有尺寸，说明弹层不增加滚动条。
- 设置中的估值、采样状态和完整依据随数据更新，保留用户主动折叠的状态及其他尚未保存的设置。
- 没有有效样本或历史估值时，仍可进入设置查看采样规则与核验原因；历史参考和重新核验中的旧结果继续明确标识。

## 数据与升级说明

- 本版只调整信息展示与交互，不修改计价、Token 归属或额度采样算法，不清除历史，也不要求重新采样。
- 原有采样修复、清除计算历史和重新开始采样按钮仍保留在“每周容量估算（实验）”中。
- API 等价估算仍是按有效采样工作负载计算的参考值，不是订阅账单或固定套餐额度承诺。

## 验证与安装说明

- 200 项核心回归与 14 项原型／公开仓库检查通过。
- 隔离环境中的 10 个界面场景，以及中英文当前估值、历史参考、无样本和重新核验状态的详情导航、滚动、折叠与设置草稿保留检查通过。
- 自包含发行目录、MSI 结构、便携包与更新替换／回滚经过检查；未执行本机真实安装升级，不代表干净系统安装验收。
