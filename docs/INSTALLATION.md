# Windows 安装与卸载

从 0.8.14 起，将同版本 MSI 和发行附件 `UsageLoom-install.cmd` 放在同一文件夹，从托盘退出 UsageLoom，然后双击安装入口并确认 UAC。入口会校验安装包并沿用当前用户登记的安装目录。安装仍为当前用户范围，提权只用于安装器安全维护回滚文件，不会让应用默认以管理员身份运行。

旧版应用内更新脚本不会请求 UAC，首次升级到 0.8.14 请使用上述手动入口。直接双击未提权的 MSI 会提前停止，不修改旧文件。请勿使用另一 Windows 账号的凭据提权；无法取得同一账号的管理员授权时可使用 ZIP 便携版。

0.2.4 的快捷方式选择页提供两个独立勾选项：桌面快捷方式默认勾选，开始菜单默认勾选，都可取消。安装将按选择创建：

- 桌面「UsageLoom」快捷方式。
- 开始菜单「UsageLoom」文件夹中的启动入口及「卸载 UsageLoom」。
- Windows Installer 产品登记；安装包不设置隐藏系统组件或禁止卸载属性。

任务栏固定由用户确认：启动 UsageLoom 后，右键任务栏上的应用图标，选择“固定到任务栏”。安装向导显示此提示，不通过脚本强制固定或修改现有任务栏布局。取消开始菜单选项会同时不创建该菜单下的卸载快捷方式，但 Windows Installer 卸载登记仍保留。

快捷方式始终指向安装时选择的目录。双击程序或快捷方式会显示主窗口；关闭窗口后继续驻留托盘，托盘菜单「退出 UsageLoom」才会结束程序。需要显式后台启动时可使用 `--background`，安装包不自动设置开机启动。

卸载前从托盘退出应用，然后使用开始菜单「卸载 UsageLoom」或 Windows 设置中的卸载入口。如果提示缺少管理员权限，在同一 Windows 账号的管理员终端运行 `msiexec /x "原安装包的完整路径.msi"`。不要直接删除安装目录。

安装失败时保留日志。手动入口会显示临时目录中的独立安装日志路径；应用内升级日志位于 `%LOCALAPPDATA%\UsageLoom\updates` 下对应更新目录的 `msi.log` 和 `result.txt`。不要通过删除 `Config.Msi`、修改磁盘根目录权限或禁用回滚来绕过错误。

卸载清理程序和安装器创建的快捷方式，保留本地统计、设置和备份。原始会话日志不归安装器管理，不会删除。数据边界见[本地数据说明](LOCAL_DATA.md)。

构建时需要项目内的 WiX 6.0.2 和 `WixToolset.UI.wixext/6.0.2` 扩展；在仓库根目录使用 `wix extension add WixToolset.UI.wixext/6.0.2` 获取扩展，再运行 `scripts/build-msi.ps1`。`scripts/test-msi-package.ps1` 只读核对中文、目录对话框、快捷方式及必要资源；静态核对不能替代真实安装、目录更改和卸载测试。
