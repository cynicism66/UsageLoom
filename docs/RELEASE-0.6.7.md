# UsageLoom 0.6.7

## 软件更新

- 设置增加可展开的“软件更新”，支持简体中文与 English、手动检查、每天自动检查及发布说明。
- 确认“下载更新并重启”后自动下载对应的 Windows x64 包，核对文件大小和 GitHub SHA-256 摘要，正常退出后升级并重新启动。
- MSI 使用 Windows Installer 的升级事务，保留安装位置；ZIP 根据文件清单备份、替换，文件操作失败时回滚。非程序文件保留，同名冲突时停止更新。
- 不上传账号、Token 或日志。用户数据仍位于 `%LOCALAPPDATA%\UsageLoom\user-data\`，不参与程序替换。
- 更新备份与诊断保存在 `%LOCALAPPDATA%\UsageLoom\updates\`，本版不自动删除这些恢复材料。[详细流程与限制](https://github.com/cynicism66/UsageLoom/blob/v0.6.7/docs/UPDATES.md)

## 分页历史与周估算

- 旧缓存比分页文件保留更多历史时，在同会话完整计数序列有序匹配的前提下保留旧明细，更新物理读取位置；不根据单个相同数值删除记录。
- 持久化历史领先状态，后续追加仍重新核对连续性，防止把旧记录当新增。
- 待核对来源的影响时间范围已知时只排除重叠区间，不再让无关旧文件阻塞本周全部估算。范围或身份不明时仍保守暂停。
- 无需清空缓存或全量重建；未知模型价格政策不变，美元仍为部分 API 等价估算。

## 安装与升级

- `UsageLoom-0.6.7-win-x64.msi`：Windows x64 自包含安装版。
- `UsageLoom-0.6.7-win-x64.zip`：Windows x64 自包含免安装版，解压后运行 `UsageLoom.App.exe`。
- `SHA256SUMS.txt`：两个安装包的 SHA-256 校验值。

首次从 0.6.6 或更早版本升级仍需手动安装本版：先从托盘退出旧程序，再安装 `UsageLoom-0.6.7-win-x64.msi` 或解压 `UsageLoom-0.6.7-win-x64.zip`。以后可使用应用内更新。请保留原数据目录，不要用旧版重新扫描已更新的索引。

## 验证与限制

核心与存储回归 136 项通过；更新隔离测试覆盖正常替换、写入失败回滚、用户文件冲突、路径越界、校验失败和模拟 MSI 失败。数据库副本验证旧记录无丢失无改动，重复扫描不增加用量。

安装包尚未签名；GitHub 摘要不是独立代码签名。模拟测试和安装包结构检查不代表真实 Windows 跨版本安装验收。断电、强制结束更新程序和新版本启动后的功能问题不保证自动回滚；保留备份用于人工恢复。GitHub Release 需单独发布，git push 本身不会自动发布。
