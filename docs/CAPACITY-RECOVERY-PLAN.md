# 采样连续性修复与验收

范围：恢复机制、重启证据、异常快照、迟到日志、并发及持久化。原始 Token 与估算资格分离；不修改原始日志或正式数据库。发布另行执行。

## 实施清单

- [x] 查询失败/暂时未登录为软中断；明确换号、主动退出、配置来源变化仍保留硬边界。
- [x] 重启检查点持久化读取与重试；首次启动终点固定，重复启动不扩大推定范围。完整扫描与处理事务完成才消费，过期或身份/路径不符终止。
- [x] 重启核验允许软失败和迟到确认；重启区间仍最多 15 分钟，恢复快照等待最多 60 分钟，确认仍须同周期且索引覆盖。
- [x] 缺失/非法快照与未确认回退先隔离；后续同周期恢复可保留已确认块，异常区间不直接合并。明确持续回退重新建立基线。
- [x] 普通查询失败后的增长仅在 5 分钟内、有已归属日志且后续确认完整时续接。长离线与无法解释的增长继续隔离。
- [x] 确属其他账号和 Spark 的无时间记录不阻断当前账号续接；当前账号/未知账号无时间记录仍需可靠时间证据。既有迟到日志/归属更新全量重算机制保留，冲突事件排除。
- [x] 同值刷新和无变化扫描不再无谓作废计算；真实输入变化仍拒绝旧结果，并在 5 秒后重试。区间、历史和当前缓存统一事务，写入失败不宣告成功。
- [x] 显示中断原因分组；明确两分钟是最短确认间隔，不是完成时限。
- [x] 合并现有与新增回归：UTC、乱序/重复/冲突、认证/账号、回退/跨周/套餐、日志异常/缺价/Spark、幂等与迟到撤回、重启持久化、事务失败回滚。
- [x] 151 项核心测试通过；应用构建通过；数据库副本复算与隔离启动检查通过。未发布、未修改正式数据库。

## 安全边界

没有正常退出证据不得自动推定归属；相同账号不证明没有其他设备使用；不能凭额度反推 Token。真实账号切换、周期到期和用户主动重置不得跨越。无法定位时间的相关记录仍阻止估算，但不丢记录。保留期外的历史可能只有归档估算，不能承诺重算。

## 场景审查结果与限制

| 场景 | 处理与边界 |
| --- | --- |
| 睡眠/休眠/断电/强制退出 | 依据持久化账本重算；没有正常退出证据不推定停机期归属。不是物理断电验收。 |
| 时区/系统时钟 | UTC 时间配对；时钟回拨不无限推迟批量重试。无法纠正上游本身错误的时间戳。 |
| 乱序/缓存/重复 | 时间排序、同一时间冲突拒绝、重复事件去重。仅有接收时间时不能识别所有上游陈旧缓存。 |
| 多设备 | 无本机用量不产生样本；有本机用量也不代表排除了其他设备。结果仍是本机样本估算，不能声称官方账单准确度。 |
| 无时间戳/日志截断 | 不从旁边一条日志臆测缺失时间；已知无关账号排除影响，相关/未知范围仍保持保守。保留文件与不确定区间检查沿用。 |
| 磁盘满/损坏/数据库锁 | SQLite 同步写入及事务；估算写入失败自动重试。磁盘无法写入时无法保证未落盘额度快照恢复，不能伪造补齐。 |
| 多实例/升级/历史保留 | 现有单实例互斥与事务保留；未改数据库结构和版本号。30 天以上输入清理后只保证保留的归档结果，不保证无限期重新核验。 |
| 价格变化/未知模型 | 不改当前定价口径；无法定价不删除 Token。价格目录变更仍隔离不同口径，不假装统计口径未变。 |

## 本地验证

- 核心测试：151/151（含模拟事务提交失败、同值刷新、重启终点固定）。
- 数据库副本：15 个确认百分点、5 段、173,489,599 Token，重复当前事件 ID 为 0；仅是该副本结果。
- 界面：隔离模拟数据下，非空/空概览启动与重复导航通过；沙箱托盘添加警告不等于真实桌面托盘验收。
- 未执行真实断电、物理磁盘写满、多设备官方额度对账或安装升级；没有以这些不可验证场景宣称全部故障均可自动恢复。
