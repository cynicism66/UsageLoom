# UsageLoom 独立授权（实验）

这是查询你在 UsageLoom 中授权的账号，不是自动读取或跟随 ChatGPT 桌面 App 的当前账号。没有登录也能继续本地 Token 统计。

## 使用

### 优先验证已有 App 缓存（0.2.8）

设置中填写 App 附带的 codex.exe，Codex Home 选择已有本机目录（通常为用户目录下 .codex，不是 UsageLoom 的 authorized-backend）。点击“使用本机已有登录缓存（不重新授权）”，会切回独立进程、关闭 proxy/专用授权模式并查询。不会调用 login/start，也不复制凭据；官方后端按其原有配置加载可用缓存，可能按官方策略刷新登录。切换不删除或退出原来的专用授权。

诊断中的“登录检测”区分未识别登录、官方稳定 ID 和本地账户指纹。官方未返回稳定 ID 时，UsageLoom 可以使用账号响应中的邮箱在内存中生成本机 HMAC 指纹，但不保存或显示邮箱。该指纹可以可靠区分本机缓存账号的切换，但不单独证明它就是桌面 App 界面当前显示的账号。

0.3.7 起，有官方 ID 或可生成本地指纹时，额度状态、周容量样本和通知去重按指纹隔离；检测到指纹变化会立即撤下旧额度并重置样本。如果官方响应既无稳定 ID 也无邮箱，仍只能在查询前后账号响应完全一致且期间无账号变更事件时显示本次快照，快照不用于通知。

### 单独授权（仅在你选择时）

1. 设置里填写本机官方 `codex.exe` 的完整路径（可使用桌面 App 附带的程序）。
2. 点击“通过官方后端登录”，阅读确认说明。
3. 在系统浏览器的官方页面完成授权，不要把授权 URL、密码或令牌贴到诊断中。
4. UsageLoom 最多等待三分钟；成功后自动查询本次授权账号额度。可以使用“取消正在进行的授权”。
5. 失败时复制“诊断与关于”中的脱敏诊断，包含连接阶段但不包含授权链接。

## 缓存与退出

官方后端使用独立的 `CODEX_HOME`：正常模式位于 `%LOCALAPPDATA%\UsageLoom\user-data\authorized-backend`。不会复制你的原有 Codex 配置或登录文件。浏览器回调、凭据保存和刷新由官方后端负责，配置为专用目录的文件缓存；UsageLoom 不读取或解析该凭据文件。

该目录可能含访问令牌，请按密码保护，不上传 Git、工单或聊天。卸载应用会保留用户数据和该缓存。若希望退出，卸载前点击“退出 UsageLoom 授权账号”；此操作仅针对专用后端，不退出桌面 App，也不删除历史统计。

## 数据可信度

官方账号响应不一定提供稳定 ID。UsageLoom 优先使用官方 ID，否则使用本机密钥对邮箱计算指纹；两者的原值都不写入应用数据。这可以隔离后续额度状态，但不将本机 JSONL 历史归属给该账号，也不能当作订阅账单。

当前已通过合成协议测试；实际浏览器授权及真实额度仍需在用户电脑验证。协议依据：[官方 App Server 登录接口](https://learn.chatgpt.com/docs/app-server#auth-endpoints)。
