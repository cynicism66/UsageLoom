# ZIP 解压运行版

先从托盘退出已运行的 UsageLoom，再将 ZIP 完整解压到新的空目录，双击 UsageLoom.App.exe。不要在压缩包内直接运行，也不要只复制 exe。全部运行库和语言资源随包附带；只省略调试符号文件。

ZIP 无需执行 MSI，因此不会经历安装器的磁盘空间和文件版本计算。解压、首次启动和系统安全检查仍需要时间，不能保证瞬间完成。ZIP 不创建快捷方式或卸载登记，需要时可手动创建。

这是免安装构建，不是数据随身携带模式：统计和设置仍保存在当前 Windows 用户的本地应用数据目录，与 MSI 版共用。先退出旧进程再启动新目录，避免单实例转发到旧版。不要同时运行多个版本。

不建议用旧版本打开已升级的数据。保留用户数据备份；有需要时使用应用的备份重建功能。不要公开上传用户数据，尤其是 authorized-backend 中由官方后端保存的登录缓存。

MSI 仍保留完整安装、目录选择及快捷方式功能，其必要的 CostInitialize/FileCost/CostFinalize 检查不会被跳过。
