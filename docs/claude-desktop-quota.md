# Claude 桌面版额度

在“设置 → 数据来源 → Claude 桌面版”打开 Claude 区域的“启用数据源”，点击右上角“保存设置”或区域内“保存并重新读取”，两者都会保存 Claude 开关、目录与来源并应用变化。保存后离开设置、重新进入或重启软件，开关保持已保存状态。概览、当前额度和托盘小窗会显示独立的 Claude 区域。默认关闭，不要求在 UsageLoom 中再次登录。

Codex 与 Claude 的开关相互独立。停用 Claude 会隐藏卡片、取消正在进行的读取并停止后续缓存读取；目录和来源配置保留，不影响 Claude 软件本身。停用 Codex 会停止其扫描、查询、账号续验、采样与通知并隐藏统计，但保留历史。重新启用 Codex 会补扫可用日志，停用期间新增用量不会自动归属，也不会跨该区间估算。

## 数据来源

套餐类型可在 Claude 数据来源设置中手动选择，默认“套餐未设置”。概览、当前额度与托盘小窗显示相同套餐，并标注“手动设置”；仅用于显示，不参与额度计算，不代表自动识别的当前账号套餐。切换账号、缓存来源或订阅后请重新核对。

托盘小窗的 5 小时与每周额度各有一条剩余进度条。窗口缺失或已过重置时间时显示淡色空轨道，保留状态提示，不假定恢复满额。

- 自动检查标准安装和 Microsoft Store 安装的 Claude 数据目录。发现多个目录时，请填写需要查看的本机绝对目录；不要填写 Cache 子目录。
- 只读 `plan-usage-history.json` 和 `Cache/Cache_Data`。仅对 Claude 官方组织额度 URL 的缓存响应解压，提取 5 小时／每周利用率、`resets_at` 和原始响应时间；不扫描聊天响应正文，不读取 Cookie 或凭据。
- HTTP 缓存包含实际重置时间时显示倒计时。只有百分比历史时显示“重置时间未提供”，不按打开软件的时间倒推 5 小时，不拼接其他周期的时间。
- 两个窗口分别处理。到达某窗口重置时间但没有新快照时，该窗口显示“— / 已到重置时间 · 等待更新”，另一个窗口仍可展示。不会自动假定剩余 100%。
- 本地缓存格式属于兼容性读取，不是 Anthropic 承诺稳定的公开订阅额度 API。当前支持已验证的 Chromium Blockfile v3 和历史文件 v2；缓存格式改变会明确提示不支持。

## 刷新与来源边界

UsageLoom 的刷新只重读本地文件，不会替 Claude 发起网络请求，也不会代替用户打开或登录 Claude。启用自动刷新后，窗口可见时最短每 30 秒读取，后台最短每 5 分钟读取；手动刷新可立即重读。首次启用／启动也会读取一次。快照时间始终为缓存原有时间，超过 15 分钟标为较旧。

如果数据不更新，请在 Claude 自己的设置中查看或刷新 Usage，再回 UsageLoom 重读缓存。重新读取不能保证 Claude 已更新磁盘缓存。

组织标识只用于生成本地来源指纹，不能证明 Claude 当前登录账号。多个缓存来源、同一时间相互矛盾的响应、换目录或所选来源消失时，不会自动混合数据。在设置中选择来源后仍应对照 Claude Usage 核验；没有可读的当前身份凭据，无法保证立即识别退出登录或所有换号情形。

文件正在写入时进行有限重试，读取失败或损坏时撤下数值，不将旧快照冒充新结果。读取有尺寸、条数、解压大小、取消和时间限制；拒绝目录链接和网络共享路径，不锁住或修改 Claude 文件。

## 额度历史（概览中的辅助折叠区）

在“概览 → Claude”查看近 1／7／30 天的额度历史。读取现有百分比历史文件和额度响应缓存，并在 UsageLoom 数据目录的独立 `claude-quota-history.db` 中保留最近 31 天的观测。仅保存来源指纹、原始快照时间、窗口、已用百分比、缓存提供的重置时间和来源类型，不保存聊天正文、Cookie 或登录凭据。停用数据源停止后续读取和保存，已有历史保留；Codex 的修复、清除和重新采样不会操作此数据库。

5 小时与每周额度分别展示，不能相加。重复快照去重；同时间矛盾记录标为冲突，不参与计算。只有同一已知重置周期、相邻间隔不超过 15 分钟且百分比未回退时才连线并计算增长。缺少重置时间、跨周期、回退或长间隔时断开，不推算缺失区间，也不将百分点换算为 Token 或费用。周期增长仅为可核验相邻快照的部分观察，并非完整周期总消耗。

每个来源最多保留 4 万条窗口记录，并限制在最近 31 天内。图表最多显示所选时段最近 600 条窗口记录，统计使用整个时段；原始明细显示最近 20 条。记录起止时间不等于连续覆盖。后台未运行、Claude 未更新缓存或旧记录已清理时无法补回不存在的快照。

无法读取来源或来源冲突时，暂不显示历史，数据库中的既有记录不会被当作当前额度。持久化失败时仍显示本次可读取的快照并给出提示，重新读取可重试。缓存来源指纹不等于经过验证的当前账号身份。

## 本机 Claude Code Token

在 Claude 设置区域单独启用“读取本机 Claude Code Token 日志”，默认关闭；右上角保存与区域内保存都支持此开关和独立 Home 路径。留空使用 `CLAUDE_CONFIG_DIR`，未设置时使用用户目录下的 `.claude`，只扫描其中 `projects` 下的会话 JSONL 和 `subagents` 会话文件。不要把 Home 填成 `projects` 或 Claude 桌面缓存目录。

“概览 → Claude”以 Token 统计为主：与 Codex 一样可选今日、近 7 天、本周、本月和自定义日期；单日按本地小时，其余按本地日期汇总。页面采用一致的本机历史分解、四栏指标、趋势图、模型分布和最近 Session 布局。没有可识别日志时显示未取得，不将缺口当作零。“模型与项目”和“Session 明细”的 Claude 标签显示对应本机统计。Session 仅显示匿名标识。额度历史折叠在主统计之后，图表不叠加坐标；条件充分时，额度卡片另行给出实验性的本机 Code 对照。Codex／Claude 切换按钮位于页面固定标题区，不随内容滚动。

仅提取时间、模型、项目目录、回复／请求身份、匿名会话标识、四个计数及缓存写入有效期细分。总 Token = 普通输入 + 输出 + 缓存读取 + 缓存写入；嵌套缓存 TTL 明细不重复累加。按 `message.id` 与请求身份去重，使用最新时间的计数快照；缺请求身份时限定同会话，子代理父回复重放优先保留父记录。`uuid` 不作为流式回复身份。缺少可识别身份或完整计数时保守跳过。

扫描经过原始文件字节，但跳过正文／代码／工具内容，只在内存保留白名单元数据；不复制原文件、不持久化 Token 明细、不上传、不读取凭据。未变化文件复用内存结果，变化文件重读；半行等待补齐，关闭来源取消扫描并清空内存。重新启动重新扫描，源文件删除后对应统计不再保留。每次最多检查 2 万文件，单文件 128 MiB、单行 4 MiB、读取预算 512 MiB，并设条数和超时限制；超过限制显示部分数据而非完整统计。

这些是本机日志用量，不是权威账单，也不能证明属于当前 Pro 账号。概览中的“部分估算 · API 等价值”按 2026-09-23 核对的[官方 Claude API 价格](https://platform.claude.com/docs/en/about-claude/pricing)分别估算已识别模型的普通输入、输出、缓存读取和写入；未知模型不参与金额，缺少写入有效期时按 5 分钟基础价并提示。快速模式、区域、批处理、工具费及历史价格变化未核实，定价覆盖率只表示已收录模型的 Token 比例。未获得 Chat、Cowork、网页、移动端或其他来源的日志时，不代表其没有用量，单凭套餐百分比不能补算 Token 或推断 Pro 每周总容量。图中的空桶仅代表所选日志无观测。项目列显示目录编码，不根据聊天正文猜测项目名称。

“概览”和“当前额度”的 Claude 卡片提供实验性的每周额度参考估算：只在 15 分钟内的有效额度快照给出当前每周重置时间、本机 Code 日志完整，并有至少 2 段、合计 5 个百分点的同来源同周期连续样本时，将各段 `(起点, 终点]` 内的本机 Token 与同期每周已用百分比增量配对，再按观察到的比例外推“同工作负载的本机 Code Token／周”。间隔超过 15 分钟、快照冲突、额度增长却没有对应本机日志、样本比例差异过大时不显示数字；来源或日志不完整也不估。模型价格覆盖至少 95% 才附带同工作负载的 API 美元等价值。界面会显示采样进度或不能估算的原因。

这不是 Claude 公布的固定 Token 容量或剩余额度：本机日志没有可信的当前账号身份，可能包含 API／其他账号记录；[Claude 的用量限制跨 Chat、Code 和桌面版共享](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)，云端 Code、Cowork、网页和其他设备不一定在本机日志中。其他渠道与本机 Code 同时用量无法完全识别，模型、缓存和功能的计量权重也可能变化。只有当前工作负载及来源不变的条件下，这个配对值才有参考意义。缓存中的剩余百分比仍是展示当前额度的优先数据；不用推算值覆盖它。

格式依据：[Claude 官方本地目录说明](https://code.claude.com/docs/en/claude-directory)、[官方缓存 Token 口径](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。参考核对了 [ccusage 的 Claude Code 数据来源说明](https://ccusage.com/guide/claude/)，不依赖安装或运行 ccusage。

## 尚未接入的能力

- 不提供 Claude 全账号的 Token 账本、账单或官方每周总容量；实验性本机 Code 对照不是 Pro 实际费用，本机回复数也不等于用户消息数。
- 不合并两个服务商的百分比，不修改 Codex 的账号归属、数据库和采样历史。
- 不提供 Claude 额度通知、主动联网查询、OAuth 登录或跨设备用量明细。

首次验证使用 Windows Claude 桌面版 2.2553.1.0（Pro）。其他安装／缓存格式可能需要适配，不应把“未发现”解释为未安装或无用量。
